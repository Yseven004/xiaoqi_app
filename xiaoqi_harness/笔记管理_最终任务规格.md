## 产品概述

笔记管理是小七App V1.0的核心管理功能，解决用户"记了找不到"、"笔记变黑洞"、"整理焦虑"三大痛点。V1.0的设计理念是**不做分类系统**，用"搜索+时间筛选"替代分类，降低整理成本，让用户把精力放在记录而非整理上。

|------|---------|---------|

### 核心用户故事

**US-1：浏览所有笔记**  
作为一名终身学习者，我想要在一个统一的列表中看到我所有的文字笔记和拍照记录，按时间倒序排列，以便快速找到最近记录的内容。

**US-2：搜索笔记**  
作为一名终身学习者，我想要通过关键词搜索笔记的标题和正文内容，以便在笔记数量增多后仍能精准找到需要的信息。

**US-3：筛选笔记**  
作为一名终身学习者，我想要按笔记类型（文字/拍照）和时间范围（今天/近7天/近30天/全部）筛选笔记，以便快速缩小查找范围。

**US-4：批量删除笔记**  
作为一名终身学习者，我想要长按进入多选模式批量删除不需要的笔记，并在删除后可以撤销，以便高效清理过时内容而不用担心误删。

**US-5：每日回顾**  
作为一名终身学习者，我想要每天看到系统随机推送的几条历史笔记，以便重新发现和温习已经遗忘的知识。

#### 2. SQL 查询实现要点

```sql
-- queryNotes 核心SQL（动态WHERE拼接）
SELECT * FROM notes
WHERE is_deleted = 0
  AND (?1 IS NULL OR title LIKE '%' || ?1 || '%' OR content LIKE '%' || ?1 || '%')
  AND (?2 IS NULL OR type = ?2)
  AND (?3 IS NULL OR created_at >= ?3)
  AND (?4 IS NULL OR created_at <= ?4)
ORDER BY created_at DESC
LIMIT ?5 OFFSET ?6;

-- getDailyReviewNotes
SELECT * FROM notes
WHERE is_deleted = 0
  AND created_at < ?  -- 7天前的时间戳
ORDER BY RANDOM()
LIMIT ?;
```

#### 3. 索引优化

已有索引：`type + is_deleted + created_at` 复合索引（拍照笔记任务已建）。  
新增验证：确认该索引对搜索+筛选组合查询有效。关键词搜索使用 LIKE 无法走索引，但在 V1.0 数据量级（<5000条）下全表扫描可接受（<200ms）。

#### 4. 数据模型无需修改

现有 `Note` model 已包含所有字段（id, type, title, content, photo_path, book_name, book_page, created_at, updated_at, is_deleted），无需新增字段。

### 状态管理方案

笔记管理页作为 StatefulWidget：
- 使用 `setState` 管理：搜索关键词、筛选条件、多选模式、选中ID集合、分页状态
- 搜索防抖：使用 `Timer` 实现 300ms 防抖，避免每次键入都触发查询
- 分页加载：`ScrollController` 监听滚动到底部触发下一页加载

### 路由与页面架构

笔记管理作为独立页面，通过首页底部导航或入口进入：
- `lib/pages/note_management_page.dart` — 笔记管理主页
- `lib/pages/daily_review_page.dart` — 每日回顾页

### 技术风险与缓解

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| LIKE 模糊搜索性能 | 低 | V1.0数据量小（<5000条），<200ms可接受；V2.0考虑FTS5全文检索 |
| 批量删除大量笔记 | 低 | 单次最多选中200条，IN 查询在sqflite中性能良好 |
| 撤销删除的数据一致性 | 中 | restoreNotes 方法检查笔记是否存在，避免恢复已物理删除的数据 |
| 每日回顾RANDOM()性能 | 低 | 数据量<5000时RANDOM()排序<50ms |
| 搜索+筛选组合条件复杂 | 低 | 动态SQL拼接，最多4个条件组合，逻辑清晰 |

#### 1.1 queryNotes — 统一组合查询

```dart
/// 统一笔记查询（支持搜索、类型筛选、时间筛选任意组合）
/// 所有参数可选，null表示不做该维度的过滤
Future<List<Note>> queryNotes({
  String? keyword,
  String? type,
  DateTime? startDate,
  DateTime? endDate,
  int limit = 50,
  int offset = 0,
}) async {
  try {
    final db = await database;
    final where = <String>[];
    final args = <dynamic>[];

    // 固定条件：未删除
    where.add('is_deleted = 0');

    // 关键词搜索：模糊匹配 title + content
    if (keyword != null && keyword.trim().isNotEmpty) {
      where.add('(title LIKE ? OR content LIKE ?)');
      args.add('%${keyword.trim()}%');
      args.add('%${keyword.trim()}%');
    }

    // 类型筛选
    if (type != null && type.isNotEmpty) {
      where.add('type = ?');
      args.add(type);
    }

    // 时间范围
    if (startDate != null) {
      where.add('created_at >= ?');
      args.add(startDate.toIso8601String());
    }
    if (endDate != null) {
      where.add('created_at <= ?');
      args.add(endDate.toIso8601String());
    }

    final result = await db.query(
      'notes',
      where: where.join(' AND '),
      whereArgs: args,
      orderBy: 'created_at DESC',
      limit: limit,
      offset: offset,
    );

    return result.map((map) => Note.fromMap(map)).toList();
  } catch (e) {
    debugPrint('[XiaoQi] DB: queryNotes error: $e');
    rethrow;
  }
}
```

#### 1.3 batchSoftDelete — 批量软删除

```dart
Future<int> batchSoftDelete(List<int> noteIds) async {
  try {
    if (noteIds.isEmpty) return 0;
    final db = await database;
    final placeholders = noteIds.map((_) => '?').join(',');
    return await db.rawUpdate(
      'UPDATE notes SET is_deleted = 1, updated_at = ? WHERE id IN ($placeholders) AND is_deleted = 0',
      [DateTime.now().toIso8601String(), ...noteIds],
    );
  } catch (e) {
    debugPrint('[XiaoQi] DB: batchSoftDelete error: $e');
    rethrow;
  }
}
```

#### 1.4 getDailyReviewNotes — 每日回顾随机查询

```dart
Future<List<Note>> getDailyReviewNotes({
  int minDaysAgo = 7,
  int limit = 5,
}) async {
  try {
    final db = await database;
    final cutoff = DateTime.now()
        .subtract(Duration(days: minDaysAgo))
        .toIso8601String();
    
    final result = await db.rawQuery(
      'SELECT * FROM notes WHERE is_deleted = 0 AND created_at < ? ORDER BY RANDOM() LIMIT ?',
      [cutoff, limit],
    );
    
    return result.map((map) => Note.fromMap(map)).toList();
  } catch (e) {
    debugPrint('[XiaoQi] DB: getDailyReviewNotes error: $e');
    rethrow;
  }
}
```

@override
void initState() {

Future<void> _loadReviewNotes() async {
  try {
    final notes = await DatabaseService.instance.getDailyReviewNotes(
      minDaysAgo: 7,

    setState(() {

}
