# 小七项目工程底线（Engineering Minimums）

> 本文件规定所有代码必须遵守的工程规则，确保稳定性和可维护性。  
> **UI 数值（圆角、边距、背景色、字体大小等）不在此文件限制，由 UI 设计师根据设计需求决定。**

## 1. 目录结构
lib/
├── config/ # 全局常量（颜色、字体等）
├── models/ # 数据模型
├── services/ # 业务服务（数据库、API）
├── pages/ # 页面
├── widgets/ # 可复用组件
└── utils/ # 工具函数


## 2. 命名规范
- 文件名：`snake_case`
- 类名：`PascalCase`
- 变量/方法：`camelCase`
- 私有成员：以 `_` 开头

## 3. 代码风格
- 字符串使用**单引号**。
- 所有 `async` 函数必须用 `try-catch` 包裹，并向用户显示友好错误提示。
- 日志格式：`debugPrint('[XiaoQi] 模块名: 内容')`，禁止使用 `print`。
- 所有颜色、字体、边距等值必须从 `config/` 下的常量引用（如 `AppColors.xxx`），禁止硬编码十六进制值或数字。

## 4. 状态管理（V1.0）
- 只使用 `StatefulWidget` + `setState`，禁止引入 `provider` / `riverpod` / `bloc` 等状态管理框架。

## 5. 数据库
- 使用 `sqflite`，所有数据库操作必须封装在 `DatabaseService` 单例中。
- 删除记录使用软删除（`is_deleted = 1`）。

## 6. 禁止事项（红线）
- ❌ 禁止在 UI 代码中直接调用 API 或数据库（必须通过 service）。
- ❌ 禁止自动添加未在任务规格中要求的依赖。
- ❌ 禁止在 UI 代码中写入固定的颜色/尺寸数值（必须从 config 引用）。
- ❌ 禁止使用 `print`。

## 7. 允许自由定义的 UI 属性（不再约束）
- 圆角（borderRadius）
- 内外边距（padding, margin）
- 背景色（backgroundColor）—— 但需从 `AppColors` 引用，不能硬编码新色值（色值需先加到 `colors.dart` 中）。
- 字体大小、行高、字重
- 阴影、透明度、动画曲线等

> **设计自由**：UI 设计师可以根据 `design.csv` 或用户需求任意选择上述数值，只要不违反工程底线即可。
