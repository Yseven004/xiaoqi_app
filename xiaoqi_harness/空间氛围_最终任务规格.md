# 空间氛围 — 最终任务规格

## 一、功能定位

### 一句话定义

空间氛围是**小七的情绪弥漫到了空气中**——用户说不清哪里在动，但关掉会觉得少了什么。

### 设计原则

1. **存在但不打扰**——用户不应该"注意到"氛围在动
2. **有光源**——空间不是均匀发光，小七在右下角，那里有一盏"灯"
3. **极简至上**——V1.0只做背景呼吸 + 情绪联动 + 光晕 + 开关

### 不做的事

| 不做 | 理由 |
|------|------|
| 情绪脉冲（互动后空间短暂变亮） | V1.0不做，增加复杂度，体验收益待验证（技术架构师建议，产品经理同意） |
| 多种氛围主题 | V1.0只做一种 |
| 深色模式氛围 | V1.0不做深色模式 |
| 粒子效果/光斑 | 抢注意力，违背"存在但不打扰" |
| 自定义呼吸周期 | 用户不需要感知"呼吸"这个概念 |
| 音效/白噪音 | 空间氛围是视觉的，不是听觉的 |

## 二、核心功能

### 功能1：背景呼吸动效

#### 呼吸曲线（UI设计师改进方案）

```
|  吸气  |屏息|    呼气     |
|  3.5s  |0.5s|    6s       |
|  渐亮  |停顿|    渐暗      |
```

真实呼吸是"吸短呼长"，不是对称的ease-in-out。0.5秒屏息是"呼吸之间的那个停顿"——用户说不清为什么，但会觉得"这个动效更自然"。

#### 色值范围（暖色偏移）

| 阶段 | 色值 | 说明 |
|------|------|------|
| 最暗（呼气末） | `#FAFAFA` | 标准背景色，AppColors.background |
| 最亮（吸气末） | `#FBFAF8` | 比纯灰亮色多一丝暖——像灯光的颜色 |

差异仍然是2级灰度，但"最亮"时带一丝暖色调。让呼吸不只是"亮度变化"，而是"温度变化"——像一盏灯的呼吸，而不是屏幕的闪烁。

#### 参数总表

| 参数 | 数值 |
|------|------|
| 总周期 | 10s |
| 吸气时长 | 3.5s，曲线 easeIn |
| 屏息时长 | 0.5s，线性 |
| 呼气时长 | 6.0s，曲线 easeOut |
| 色值范围 | #FAFAFA ↔ #FBFAF8 |
| 动画类型 | Color属性动画（不触发布局，GPU合成） |

#### Flutter实现要点

```dart
// 使用 AnimationController(10s) + repeat()
// 根据 controller.value (0.0-1.0) 计算当前色值
// 0.00-0.35: 吸气（easeIn渐亮）
// 0.35-0.40: 屏息（保持最亮）
// 0.40-1.00: 呼气（easeOut渐暗）
// 使用 AnimatedBuilder 包裹 Scaffold
```

### 功能2：情绪联动系统

#### 三档氛围色值

| 情绪档位 | 情绪值 | 最暗色 | 最亮色 | 视觉感受 |
|---------|--------|--------|--------|---------|
| 🌞 明亮 | ≥80 | #FAFAFA | #FFFFFF | 像阳光照进房间 |
| 🌤 标准 | 50-79 | #FAFAFA | #FCFCFC | 正常的室内灯光 |
| 🌧 柔和 | <50 | #F7F6F4 | #FAFAFA | 像阴天的自然光 |

**关键设计**：明亮档的"最亮"是纯白 #FFFFFF——V1.0唯一出现纯白的地方，暗示"小七很开心，空间在为你发光"。柔和档的"最暗"是 #F7F6F4——带暖灰调，不是冷灰。

#### 情绪过渡

| 参数 | 数值 |
|------|------|
| 档位过渡时长 | 3s |
| 档位过渡曲线 | easeInOutCubic |
| 过渡方式 | 当前色值 → 目标档位的色值，两组色值同时渐变 |

#### 通信机制

- AtmosphereService 监听 EmotionService 的情绪值变化回调
- 情绪值跨档位时，触发3秒过渡
- 情绪值在档位内波动时，不触发过渡（避免频繁微调）

### 功能3：小七光晕

#### 设计理念

小七在右下角，那里有一盏"灯"。光从那里散发出来，弥漫到整个空间。用户潜意识会感受到"这个空间的温度来自小七"。

#### 视觉规格

| 参数 | 开心（≥80） | 平静（50-79） | 低落（<50） |
|------|------------|--------------|------------|
| 光晕半径 | 120px | 80px | 50px |
| 中心透明度 | 6% | 4% | 2% |
| 边缘透明度 | 0% | 0% | 0% |
| 光晕颜色 | accent (#D4A574) | accent (#D4A574) | accent (#D4A574) |
| 呼吸同步波动 | ±10px | ±5px | ±5px |

#### 呼吸同步

- 光晕的半径波动与背景呼吸同周期（10秒）
- 吸气时光晕变大，呼气时光晕变小
- 使用同一个 AnimationController 的 breathePhase 参数

#### 实现要点

- RadialGradient + Positioned，位于小七上方
- 与背景呼吸共用 breathePhase
- 位于 OverlayEntry 中（与情绪机器人同一层级）

## 三、页面行为

### 跨页面连续性

- 背景呼吸不随页面切换重置——全局 AtmosphereService
- 切换页面时，呼吸从当前相位继续，不跳回起点
- 光晕在所有页面都可见（全局Overlay）

### 登录页特殊处理

- 登录页有独立的"七"粒子动效
- 空间氛围从主页开始——登录页不使用背景呼吸
- 登录成功进入主页的瞬间，背景从静态 #FAFAFA 开始第一次呼吸

### 全屏页面处理

- 相机页（拍照记录）：隐藏氛围（全屏沉浸式）
- 其他页面：正常显示
