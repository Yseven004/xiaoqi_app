# 情绪机器人小七 — 最终任务规格

## 一、功能定位

### 核心理念

**小七不是"效率助手"，是"学习伙伴"。**

### 设计原则

* **"弱智能"设计**：小七不完美、需要关心，情感连接来自付出
* **催产素机制**：用户照顾小七→小七成长→用户满足感→更愿意学习
* **不对等关系**：小七需要用户关心，不是万能的。"被需要"比"能做什么"更重要

### 功能边界

* ✅ V1.0做：8种表情、3种手势交互、情绪状态机、主动关怀、情绪记忆
* ❌ V1.0不做：文字输入对话、语音交互、表情自定义/解锁、云同步

## 二、技术方案确认

### 架构决策

|决策|结论|
|-|-|
|状态管理|全局单例 `EmotionService` + 回调监听（不用Provider）|
|表情动画|Flutter原生 `AnimationController` + `CustomPainter`（不用Rive/Lottie）|
|悬浮组件|`OverlayEntry` 挂载在 MaterialApp 之上|
|手势方案|单击 + 长按 + 拖动（去掉双击）|
|情绪衰减|惰性计算（打开App时算时间差）|
|记忆存储|混合方案（聚合用SharedPreferences，事件流用SQLite）|

### 新增依赖

|包名|用途|必要性|
|-|-|-|
|`shared\_preferences`|轻量状态持久化|必须|
|`flutter/services` (HapticFeedback)|震动反馈|内置|

**不新增**：~~rive~~、~~provider~~、~~dotlottie\_flutter~~

## 三、任务清单（6个任务）

### 任务1：表情系统（E1-E8）

#### 功能描述

定义8种基础表情，实现表情切换动画和视觉表现。表情是小七情绪状态的外在表达。

#### 表情定义

|编号|表情名称|情绪状态|触发场景|视觉描述|动效|
|-|-|-|-|-|-|
|E1|开心|愉悦、满足|情绪值80-100（非兴奋）、用户单击|月牙眼+上扬嘴巴|轻微摇晃（±5°，1.5s）|
|E2|平静|中性、稳定|情绪值60-79，默认状态|圆点眼+微上扬嘴巴|呼吸（透明度0.85-1.0，2s）|
|E3|思考|专注、好奇|情绪值40-59、用户打开分析页|不对称眼睛+抿嘴|轻微晃动（±3°，2s）|
|E4|困倦|疲惫、想睡觉|情绪值20-39、深夜时段|横线眼+圆形嘴巴|上下浮动（±3px，3s）|
|E5|难过|失落、被忽视|情绪值0-19、>3天未打开|下垂眼+下弯嘴巴|颤抖（x轴±1.5px，0.4s）|
|E6|兴奋|期待、激动|情绪值90+、首次打开、里程碑|放大圆眼+高光+大嘴巴|跳跃（-8px，0.6s弹性）|
|E7|生气|不满、抗议|1分钟内删除>3条笔记|皱眉眼+波浪嘴|快速摇晃（±8°，0.8s）|
|E8|感动|被认可、温暖|>3天未打开后回来、连续7天|泪光眼+微笑+光晕|缩放（1.0→1.08→1.0，1.5s）|

#### 视觉规格

* 整体尺寸：60×60px（小屏52×52px，大屏64×64px）
* 外壳：圆形，填充 `#E0DCD5`（robotShell）
* 眼睛：两个圆点，直径6px，颜色 `#2C2C2C`（textPrimary）
* 嘴巴：弧线，stroke 2px，颜色 `#2C2C2C`
* 外壳阴影：`BoxShadow(blurRadius: 12, color: #00000015, offset: Offset(0, 4))`

#### 表情切换规则

* 切换动画：300ms，ease-in-out
* 旧表情淡出150ms + 新表情淡入150ms
* 特殊表情覆盖规则（优先级从高到低）：E8感动 > E7生气 > E6兴奋 > 常规映射
* 特殊表情持续时间：

  * E7生气：触发后持续10秒，然后恢复常规情绪映射
  * E6兴奋：触发后持续5秒，然后恢复常规情绪映射
  * E8感动：触发后持续3秒，然后光晕消散，表情保持到下次交互

#### 验收标准

* \[ ] 8种表情均可正确渲染，视觉区分明显
* \[ ] 表情切换动画流畅，300ms过渡
* \[ ] 每个表情包含呼吸动效（基础）
* \[ ] 特殊表情覆盖常规情绪映射
* \[ ] 特殊表情持续时间正确（E7=10s，E6=5s，E8=3s）
* \[ ] 表情资源加载失败时显示默认E2平静表情

#### 技术约束

* 引用 `engineering-minimums.md`：UI组件使用StatelessWidget（纯展示）
* 引用 `engineering-minimums.md`：动画使用Flutter内置AnimationController
* 表情渲染：使用 `CustomPainter` 实现，不依赖外部动画文件

### 任务2：交互系统 + 预设对话反馈

#### 功能描述

实现3种手势交互（单击/长按/拖动），每种手势触发不同的反馈（表情变化、文字气泡、情绪值更新）。

#### 手势定义

|手势|触发条件|小七反馈|情绪影响|
|-|-|-|-|
|单击|点击小七|表情短暂E1开心（1秒）+ 文字气泡（随机文案）+ 震动|愉悦+1|
|长按|按住>500ms|表情E8感动+光晕+文字气泡"好温暖\~"+震动|愉悦+3|
|拖动|按住并移动>10px|跟随手指，松手弹回原位+文字气泡"嘿嘿\~"|无变化|

#### 单击交互流程

```
用户点击小七
├─ 立即触觉反馈：HapticFeedback.lightImpact（0ms）
├─ 表情切换：当前表情 → E1开心（300ms过渡）
├─ 文字气泡出现：从下方滑入（200ms）
│   文案池：\["嗨\~", "嗯？", "在呢\~", "嗨嗨！", "来啦\~"]
├─ 1秒后：表情恢复常规情绪映射
└─ 3秒后：气泡淡出消失（300ms）
```

#### 长按交互流程

```
用户按住小七（>500ms触发）
├─ 触觉反馈：HapticFeedback.mediumImpact（500ms时）
├─ 表情切换：→ E8感动（300ms过渡）
├─ 光晕出现：accent色柔和光晕（opacity 0→0.3，400ms）
├─ 文字气泡："好温暖\~"
├─ 持续按住期间：保持E8+光晕呼吸（opacity 0.2-0.4，1.5s周期）
└─ 松手后：
    ├─ 表情恢复（300ms）
    ├─ 光晕消散（opacity 0.3→0，500ms）
    └─ 气泡3秒后消失
```

#### 拖动交互流程

```
用户按住并移动（>10px位移触发拖动）
├─ 小七跟随手指移动
├─ 透明度：1.0 → 0.7（进入拖动态）
├─ 表情：保持当前表情，眼睛跟随移动方向
└─ 松手后：
    ├─ 弹回右下角原位（spring动画：stiffness=250, damping=18）
    ├─ 透明度恢复1.0
    ├─ 气泡："嘿嘿\~"
    └─ 气泡3秒后消失
```

#### 手势冲突处理

```
手势优先级（高→低）：长按 > 拖动 > 单击

判定逻辑：
按下后：
  0-100ms：等待，不触发任何手势
  100-500ms：
    ├─ 有位移（>10px）→ 判定为"拖动"，取消长按判定
    └─ 无位移 → 继续等待
  >500ms：
    ├─ 仍按住且无位移 → 判定为"长按"
    └─ 松手 → 判定为"单击"
```

#### 文字气泡视觉规范

* 背景：`#FFFFFF`（card色）
* 圆角：12px
* 内边距：水平12px，垂直8px
* 阴影：`BoxShadow(blurRadius: 8, color: #00000012, offset: Offset(0, 2))`
* 最大宽度：180px
* 最小高度：32px
* 文字：14sp，行高20px，颜色 `textPrimary`

**气泡动画**：

* 出现（200ms）：opacity 0→1, translateY +8→0, scale 0.9→1.0
* 消失（300ms）：opacity 1→0, translateY 0→-4px

**气泡互斥**：

* 同一时间最多显示1个气泡
* 新手势触发时：旧气泡立即淡出（150ms），新气泡延迟100ms后出现

#### 验收标准

* \[ ] 单击小七触发E1开心+文字气泡+震动，1秒后恢复，3秒后气泡消失
* \[ ] 长按小七（>500ms）触发E8感动+光晕+气泡"好温暖\~"
* \[ ] 拖动小七可自由移动，松手后弹回原位
* \[ ] 手势冲突处理正确：长按>拖动>单击
* \[ ] 文字气泡视觉正确，动画流畅
* \[ ] 气泡互斥：同一时间最多1个
* \[ ] 单击节流：快速连续点击（<300ms间隔）只响应第一次

#### 技术约束

* 引用 `engineering-minimums.md`：手势检测使用GestureDetector
* 引用 `engineering-minimums.md`：位置状态使用StatefulWidget + setState
* 引用 `engineering-minimums.md`：动画使用AnimatedPositioned或TweenAnimationBuilder

### 任务3：情绪状态机

#### 功能描述

实现小七的内部情绪状态机，根据用户行为和时间推移更新情绪值，驱动表情变化。

#### 情绪值模型

* 范围：0-100
* 初始值：50（中性）
* 更新频率：每次交互后更新 + 打开App时惰性衰减

#### 情绪值变化规则

|事件|情绪值变化|说明|
|-|-|-|
|用户单击小七|+1|轻微愉悦|
|用户长按小七|+3|强烈愉悦|
|用户完成一条笔记|+5|学习成就感|
|用户连续学习>30分钟|+10|深度学习|
|用户删除笔记|-3|负面操作|
|每分钟衰减（无互动）|0|V1.0不做分钟级衰减|
|每小时衰减（无互动）|0|V1.0不做小时级衰减|
|打开App时惰性衰减|见下方公式|基于时间差一次性计算|

#### 惰性衰减公式

```
衰减 = min(距上次互动的小时数 × 2, 30)
特殊衰减：
- >24小时未打开：额外-10
- >72小时未打开：额外-20
```

**示例**：

* 1小时后打开：衰减=min(1×2, 30)=2
* 12小时后打开：衰减=min(12×2, 30)=24
* 24小时后打开：衰减=min(24×2, 30)=30 + 额外-10 = 40
* 72小时后打开：衰减=min(72×2, 30)=30 + 额外-20 = 50

#### 情绪值→表情映射

|情绪值范围|表情|说明|
|-|-|-|
|90-100|E6兴奋（20%概率）或 E1开心（80%概率）|高愉悦|
|80-89|E1开心|愉悦|
|60-79|E2平静|中性|
|40-59|E3思考|略低落|
|20-39|E4困倦|低能量|
|0-19|E5难过|严重低落|

#### EmotionService 核心设计

```
EmotionService（单例）
├── 状态：moodScore(int), currentEmotion(enum), isVisible(bool)
├── 持久化：SharedPreferences（moodScore, lastInteractionTime）
├── 事件处理：handleEvent(EmotionEvent) → 更新moodScore → 通知listener
├── 冷启动恢复：init() → 读SharedPreferences → 计算时间差衰减 → 设置初始状态
└── 清理：dispose() → 取消Timer → 清除listener
```

#### 验收标准

* \[ ] 情绪值初始化为50
* \[ ] 用户交互后情绪值正确更新
* \[ ] 打开App时惰性衰减正确计算
* \[ ] 情绪值→表情映射正确
* \[ ] 特殊表情在特定条件下触发（E7生气、E8感动）
* \[ ] 情绪值范围严格限制在0-100
* \[ ] 情绪值持久化到SharedPreferences
* \[ ] 冷启动恢复正确

#### 技术约束

* 引用 `engineering-minimums.md`：状态管理使用StatefulWidget + setState
* 引用 `engineering-minimums.md`：数据持久化使用SharedPreferences（轻量）+ SQLite（历史）
* 引用 `engineering-minimums.md`：全局单例Service + 回调监听

### 任务4：主动关怀系统

#### 功能描述

小七能够识别用户的"低能量时刻"，主动发起关怀互动。

#### 关怀场景定义

|场景|触发条件|小七行为|文字气泡|气泡时长|
|-|-|-|-|-|
|首次打开（当日）|当天首次打开App|E1开心|"来啦\~今天也要加油哦！"|5秒|
|久别重逢|>3天未打开后打开|E8感动+光晕|"好久不见！想你了\~"|5秒|
|深夜关怀|23:00-06:00打开App|E4困倦|"这么晚了，注意休息哦\~"|5秒|
|连续学习|连续使用>60分钟|E2平静|"学了好久啦，休息一下？"|5秒|
|无互动|打开App后>5分钟无操作|E3思考|"在想什么呀？"|5秒|
|学习成就|完成第10/50/100条笔记|E6兴奋|"哇！第{N}条笔记了！"|5秒|

#### 关怀气泡视觉差异

* **普通交互气泡**：背景 `#FFFFFF`，无边框
* **主动关怀气泡**：背景 `#FFFFFF`，左边框3px accent色条（`#D4A574`）

#### 关怀触发规则

* 打开App后，延迟1.5秒再触发关怀气泡
* 多个关怀场景同时满足时，只触发优先级最高的一个
* 同一场景24小时内不重复触发
* 关怀触发后，用户点击小七可以立即关闭气泡

#### 关怀优先级（高→低）

1. 久别重逢
2. 学习成就
3. 深夜关怀
4. 连续学习
5. 无互动
6. 首次打开

#### 验收标准

* \[ ] 6种关怀场景正确触发
* \[ ] 关怀气泡左侧有3px accent色条
* \[ ] 延迟1.5秒后触发关怀
* \[ ] 同一场景24小时内不重复触发
* \[ ] 多场景同时满足时，触发优先级最高的
* \[ ] 点击小七可立即关闭关怀气泡

#### 技术约束

* 引用 `engineering-minimums.md`：时间判断使用DateTime.now()
* 引用 `engineering-minimums.md`：数据查询使用DatabaseService单例
* 关怀去重：记录最近一次关怀时间+类型，避免重复
