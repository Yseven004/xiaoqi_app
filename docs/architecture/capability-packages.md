# 官方能力包

小七负责界面、Agent、上下文、任务状态、通用工具、安装与授权，以及聊天、笔记和附件等用户数据。能力仓库存放专用说明、流程、脚本、模板、素材、依赖声明和发布记录。

## 仓库和包

源码与发布包由公开仓库 [`Yseven004/xiaoqi-capabilities`](https://github.com/Yseven004/xiaoqi-capabilities) 管理。每个目录是一个可独立版本化、独立发布的包：

| 包目录 | 展示名称 | 类型 |
| --- | --- | --- |
| `study-notes-studio` | 学霸笔记图 | skill |
| `book-to-skill` | Book to Skill | skill |
| `original-reading-annotations` | 原文批注 | plugin |
| `learning-notes-manager` | 学习笔记管家 | plugin |

`xiaoqi-capability.json` 声明稳定 ID、语义版本、宿主 API、所需工具、运行依赖和能力声明。`PROVENANCE.json` 与许可证随包发布。包发布校验源码提交、不可变版本标签、归档 SHA-256，并更新 `catalog.json`。发布一个包不会升级其他包或重建小七服务。

## 导入、更新和版本固定

小七只信任固定 GitHub 仓库索引。索引和归档经过 HTTPS 来源、大小、版本、清单及 SHA-256 校验；校验失败时保留当前目录和已安装包。索引暂不可用时继续使用上次已核验的本地目录。

检查新版和安装新版都由用户在现有能力管理入口手动发起。安装新版保留旧归档、安装身份、用户开关和权限状态；不会自动授权清单中声明的工具。撤销授权和停用仍立即生效。

每个任务把显式选中或自动发现的能力绑定到实际使用的版本。安装新版不改变现有任务绑定，新任务使用当前默认版本。管理入口可把已安装能力切回已保留版本；版本切换不回滚聊天、笔记、附件或进行中的任务。

## 宿主能力声明

包声明需要的宿主工具时，小七仍按既有权限流程检查和授权。包可以声明受支持的宿主能力，例如 `image.annotate_original` 和 `learning_notes.append`；只有从可信官方发布安装、用户启用并在当前工作中选中的具体版本，其声明才参与宿主功能路由。声明本身不创建授权，切回旧版本时也使用旧版本自己的声明。

首批没有独立运行的在线 MCP 服务。未来如有在线 MCP，代码与发布包仍放在能力仓库，服务部署位置单独登记；小七复用现有 MCP 连接和授权能力。

## 检查与发布边界

能力仓库分别检查包格式、脚本和素材；包的更新不触发小七服务镜像构建。小七服务改动按服务、执行器、代理和部署脚本的影响范围选择检查与组件构建。服务发布仍执行版本契约、数据核对、健康检查和自动回滚。生产部署授权与此文档无关，必须保持用户明确授权状态。
