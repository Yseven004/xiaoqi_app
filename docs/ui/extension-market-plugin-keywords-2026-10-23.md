# 插件能力关键词 · 2026-10-23

## 已确认与入口

用户确认补齐插件能力关键词的读取、编辑、保存，与技能使用同样的输入和搜索规则。复用 `marketKeywordsField` 和 `MarketDialog`，无新依赖、无新增图标。

1. 插件列表“…” → “编辑能力关键词”；详情“管理”中也有同一入口。
2. 输入3～5个用途关键词（建议数量，逗号分隔），点击保存；取消不提交。空列表表示主动清空。
3. 自定义MCP连接设置也复用同一输入组件。关键词保存后可参与个人插件搜索，公开目录仅使用发布方声明的关键词。

## 数据与接口

- 新导入插件读取 `plugin.json` 中的 `keywords`，随能力记录存储；已有插件缺少关键词字段时，从当前不可变包中的 `.claude-plugin/plugin.json` / `.codex-plugin/plugin.json` / `plugin.json` 读取，不改变包内容。缺失/损坏的元数据不隐藏已有插件，仍可手动填写。
- 插件关键词通过既有 `PATCH /v1/capabilities/<id>/visibility` 的 `keywords` 列表保存，要求匹配 `expected_revision`，只更新当前账号的插件。技能继续通过技能编辑器保存元数据。
- 显式编辑标记 `keywords_edited` 保留用户的自定义词及主动清空；后续更新插件不覆盖。未编辑过的声明词可随新清单更新。
- 保存成功先把服务器返回记录写入本机，避免随后刷新失败却提示“未保存”。冲突时取回当前版本并保留输入，用户确认后可重新提交；不静默覆盖并发修改。
- MCP公开清单、安装记录和连接设置支持关键词；编辑连接时保留原凭据及已有连接信息。关键词不会包含令牌或改变执行权限。
- 服务端只接受文字列表，最多32项、每项最多80字符，去除首尾空白、空项和大小写重复。推荐3～5个与技能一致；上限用于输入边界保护。
- 共用检索器仍按名称/别名、关键词、简介、作者匹配排序。读取/编辑关键词不自动公开私人插件。
