# 插件搜索字段 · 2026-10-23

## 已确认与入口

用户确认只需要搜索，不需要给插件或技能手动添加、保存能力标签。搜索使用现有内容源提供的信息，不再提供关键词编辑入口。

1. 插件搜索匹配名称、简介、包清单声明的关键词，以及导入清单解析出的组件名称和能力说明。
2. 技能搜索匹配名称、简介及原始技能元数据中已有的字段；编辑器不再要求填写关键词。
3. 公开 MCP 搜索可使用目录自身提供的关键词；个人 MCP 连接不提供手工关键词字段。

## 数据与接口

- 插件包导入时读取清单关键词和组件信息。已安装插件的检索字段以当前不可变包为准，忽略旧版本保存的自定义关键词；不改变包内容。
- `PATCH /v1/capabilities/<id>/visibility` 只修改展示和启用状态，不再写入关键词。
- MCP公开目录可继续使用目录原有关键词；个人连接只检索名称与地址，不存储用户手工关键词。
- 共用检索器按名称/别名、来源关键词、组件能力说明、简介与作者匹配。私人插件仍只在个人搜索中出现。

统一 release：`2026-10-23-extension-search-1`，API contract：`20`；客户端和服务端同步修改。旧客户端须重建后使用，版本不匹配继续阻止受影响请求并显示更新指引。

- 搜索只读取来源清单及解析出的能力信息，不改动插件包、技能正文、密钥或权限。
