## 素材与状态

- 复用项目既有 search / search-light / gear / caret-down 图标。两组分段共用独立容器与白色底板SVG；分类使用普通 / 蓝色选中两种独立SVG；文字和交互均为原生控件。
- 底板SVG路径保持不变，只由选中状态调整布局位置，避免切换不同整组SVG时异步加载造成底形滞留；触控层与底板共用等宽分段约束。
- 切换插件 / 技能后恢复公开、推荐、空搜索；公开 / 个人仅控制相应内容。个人隐藏公开分类；搜索期间仍能切换公开 / 个人。
- 已安装内容保留独立区域及详情入口。公开推荐目前没有内容源，所有分类展示真实空状态，不添加演示数据，不把个人记录充当公开内容；分类只决定公开区域的当前视图。
- 加载沿用静态骨架，错误沿用现有重试，添加和连接管理保留。无新增后端或API。
