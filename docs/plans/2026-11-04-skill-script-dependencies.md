# 技能脚本的任务依赖闭环

用户确认范围：execute_skill_script 与通用执行入口共享安装、确认、复用逻辑；不新增工具。不解析新的依赖文件格式，不支持系统级安装。

依据：AI-Agents-in-Depth 第四章 §4.2、§4.8；Genkit Dart 官方工具与中断接口。研究记录位于 .codex-artifacts/research/2026-11-04-agent-tool-design.md。

参考：https://genkit.dev/docs/dart/tool-calling/ 、https://genkit.dev/docs/dart/middleware/ 。SDK 当前固定为 1.0.0；使用现有 ToolResult.interrupt 和批准恢复逻辑。

## 实现

- 两个执行入口共享 dependencies schema 与 prepareExecutionDependencies 内部流程，统一用途校验、官方包源批准、任务依赖准备、依赖复用、锁文件合并和冲突拒绝。
- 技能执行先校验已加载技能、真实脚本路径与参数，再准备依赖。拒绝和安装失败均返回结果，不执行原脚本。
- 技能脚本成功结果包含 ok/data/output 和任务依赖摘要，明确标记复用状态。技能脚本本身的联网权限仍单独校验，安装批准不授权脚本访问网络。
- 客户端/服务端共享 release 2026-11-04-skill-script-dependencies、API 合同 30；没有数据迁移。旧客户端需要重新构建以匹配合同。

## 定向验证

新增本地模拟运行场景覆盖批准、拒绝、安装失败，以及技能执行后由通用入口复用依赖（仅一次安装、无第二次确认）。另运行原有联网脚本路径、依赖准备服务相关回归与修改文件静态分析。模拟模型与安装桥接，不调用付费模型；不等价于真机或实际包源安装验收。

## 发布

遵照用户明确指示，复用同一 main 提交的 CI 产物，跳过整套付费模型运行验收；保留产物身份校验、资源预检、备份、激活、数据与健康核对、失败回滚及清理。一次性豁免使用已存在的本地运维脚本，并在成功后恢复标准发布管理脚本。未通过的检查不能标为通过。

失败降级：拒绝下载后保留原任务环境，报告不可执行原因；安装失败不运行技能脚本。发布激活失败由既有脚本恢复上个健康版本及其数据。真机验证由用户进行。
