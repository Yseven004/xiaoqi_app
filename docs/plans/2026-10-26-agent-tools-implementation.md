## 首批改动

- 服务端统一 `ExecutionLimits` 默认资源预算：工具操作 128、代码执行 128、其中技能脚本 64、单次 Agent 模型轮次 64。测试可注入小预算，客户端或模型不能自行改预算。该数值是当前实施基线，仍需真实工作流性能和资源证据；不能据此称预算优化完成。
- 每次代码尝试原子累计；失败、重新创建执行服务或恢复任务不重置计数。取消任务不允许继续认领执行预算。
- 账号内已启用能力不因前置意图推荐遗漏而被删除；执行保留本轮身份、账号版本、用户取消、外部工作流与生图预算检查。
- 模型可同时使用技能和任务内辅助代码。任务资料读取和工作区操作与外部工作流效果分开，不让 `answer` 分类直接禁用辅助计算。
- 当前任务产物按 ID 选择，或按文件名复用最新产物；保持二进制原始字节，核对任务对象前缀和 20 MB 输入预算，显式选择不存在/其他任务产物时失败。
- MCP 精确计划次数不再作为调用前授权条件，真实成功次数及交付要求仍记录。
