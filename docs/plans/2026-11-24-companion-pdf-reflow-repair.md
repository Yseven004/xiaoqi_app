2026-11-24 汇总。读者从本地、微信或网上添加资料，进入伴读后应能接着读、立即翻页，看全原书内容。以下是对截图、三段录屏、两份原书和工作区代码核对后的修复目标。文末单列上一轮已接入的代码和安装记录。本次交付为方案。

**格式边界。** 同一份 PDF 的原页和重排视图共享位置。单独导入的原生 EPUB 使用章、段和字符定位。同一本书下另有一份独立 PDF 时，现有操作是切换资料，各用自己的进度。原生 EPUB 生成可保存的 PDF 是独立功能，当前产品没有提供，本轮未确认开发。微信读书只作可观察体验的参照。

## 一、PDF 整本就绪后手动切换

1. **导入成功即后台准备。** 基于已保存原件分批提取全书的文字、结构、对象、链接和原页位置。扫描页复用端侧 OCR。复杂页能清晰、完整地以原布局展示时，记为该页的可读结果。缺页或无可读结果应记录具体页和原因。
2. **就绪前可以读 PDF。** 保持「PDF」选中，允许翻页、跳目录或退出。用「电子书准备中」说明状态。利用已知阅读视口预排；实际宽高、字号、边距、行距或翻页方式尚未确定时，先完成与屏幕无关的部分，再按实际版式排完整本。横向需要完整分页，竖向需要可连续阅读的布局和可定位的内容。
3. **整本与当前版式均完成，才提示「电子书已就绪」。** 保持当前 PDF 和阅读位置。用户随后点「电子书」时，用点击当刻的最新原文位置打开。目标正文已定位、目标首帧和手势均就绪后再替换画面。回 PDF 同样先准备目标原页。换资料或离开后，旧任务不能触发切换或把就绪提示显示在另一本书上。
4. **复用与恢复。** 沿用按资料身份、内容指纹和解析版本隔离的缓存，逐页保存成果，完整时一次发布。版式结果另含屏幕和显示参数。旋转、分屏或改字号只重新计算受影响的版式。任务中断可续做，损坏、空间不足或权限受限时说明原因并保留 PDF，允许可恢复的失败重试。限制后台并发与解码占用，避免将全书位图同时装入内存。

当前入口在一张原页可读后就展示电子书，随后预取邻页。横向分页尚未结束时，正文可能可见但手势被禁用。先核对这两个状态的切换次序，再调整显示。主要入口为 `reading_companion.dart` 的格式切换和 `reflow_document_pager.dart` 的分页发布、首屏定位与翻页开关。

## 二、双向定位与首屏翻页

用户在电子书读到一处正文或图表，切回 PDF 时显示该内容所在的完整原页。直接切回电子书，仍读到原来的位置。如果在 PDF 主动翻到另一页，电子书从翻到的那一页开头起读。目录和进度跳转也应更新到用户选定的位置。

- **录屏证据。** 视频一 38.83 秒的电子书以「第86节 蓝色对钩」开头。回 PDF 仍是该节，40.44 至 40.89 秒出现准备页，再进电子书首行已变为「那周周日的深夜……」。视频二 4.54 至 4.85 秒切换后，「3.1.3 用户记忆的四种存储格式」与四栏图仍在屏内。两段资料不同，不能据此比较引擎耗时。
- **电子书主动翻页也更新 PDF。** 横向取新屏第一处可读正文或图表，纵向取停止滚动后靠近上沿的内容，映射为原页、原段及字符或对象区域。一个电子书屏跨两张原页时取屏首所在页。连续几个电子书屏都出自同一张原页时，回到同一张 PDF 页是正确结果，切回电子书仍应恢复刚才那一屏。
- **分别验收原生 EPUB 进场。** 视频三 01:09.53 出现引言，约 01:10.03 闪过书名页三帧又返回，01:16.70 才观察到首次翻页。录屏缺少触摸事件。用冷启动和已有进度各测一次，从点击进入、目标首帧可见到第一次滑动生效分别计时；前后页能翻，后续排版不得覆盖已经显示的章节。初次打开尊重原书封面顺序，有进度时直接回到上次位置。
- **修复办法。** 复用 `ReaderPaginationPreferences` 的每书、每资料进度。在原页号上补充可恢复的原文位置，文字定位到原段及段内位置，图片或表格定位到原页中的对象区域。两种视图读取同一条进度。用户在正文滚动、翻页、放大后主动移动到别处或用目录跳转时才提交新位置。切换格式、整页适配、预读插入和预览缩放分别更新显示，不能把这些操作当作用户开始读另一段。
- **恢复与兼容。** 快速切换时沿用现有请求代次，丢弃过期加载和定位回调，核对异步写盘顺序。旧进度按原页恢复，随后随阅读补齐段落。解析缓存更新后通过原文或原页区域重定位，保留原 PDF、笔记、涂鸦、引用和旧进度的页号含义。诊断只记录操作顺序、页号和位置标识。

## 三、标题、段落和强调

《埃隆·马斯克传》共 496 张原页。第 432 页依次是「第86节 蓝色对钩」、日期、两行图说、无编号小标题「热核打击」和正文。除居中的节标题外，后四者是相同字号宋体，原书靠留白和缩进表达结构。工作区已有标题标签、编号、字号和字重判断。本机 PDFium 对该页普通宋体也返回过字重 2092，当前阈值可能导致大片普通文字标粗。实施时对照原页并在目标设备复测该返回值。

- 电子书中的章、节和小标题采用蓝色，用字号、字重与段前后间距继续区分层级。日期、图说和正文各自成段。标题与下一段尽量同屏。日夜主题、放大字号和读屏都要能区分层级；可点链接另有可辨认的样式。蓝色应用于电子书排版，原版 PDF 保持原貌。具体色值与间距用同一页的日夜稿确认。

- 原书有明确结构时，保留章、节、无编号小标题的主次及原文。先核实当前引擎实际可读取的结构信息，再结合独立成行、相对字号、字重、段前后留白和全书同类标题样式。把正文内的粗体保留在原句，图题、表题留在对象旁。扫描件结构不清时保留原貌。
- 段内换行随屏宽和字号重排，原书新段保留。跨页只有在阅读顺序和续接关系可靠时才合并，注意页眉页脚、缩进、列表、图注和栏间边界。句号本身不能证明段落结束。保留每段对应的原页位置，确保重排后还能返回原处。

## 四、完整呈现、预览并保存 PDF 图表

| 场景 | 已确认的阅读体验 |
| --- | --- |
| 正文中的普通数据表或独立插图 | 正文重排，图表留在原文对应位置，保留图题、表题及说明。宽表优先让读者看清数字，可在表内左右滑动看其余列，横滑不触发整书翻页。 |
| 需要对照旁注、配图或多个区域才能读懂的页面 | 电子书里整页保留 PDF 原布局。页内的图片、表格仍可单独预览和下载。 |
| 打开预览 | 暗色遮罩上完整显示选中的图片或表格，可放大、移动。右上角固定白色圆角「下载」按钮，带下载图标，只在预览时出现。退出回到打开前的阅读位置。 |
| 下载 | 保存选中对象的完整清晰图片。即使当前放大到一处或宽表只显示四列，文件也包含整个对象、每一行和每一列。 |

逐页对照原 PDF、识别区域、电子书显示和导出文件，查明对象在哪一步消失。以原 PDF 中的完整对象边界作为重排显示、整页点选、放大和导出的共同依据。即使决定整页展示，也需要保留页内对象的位置。下载优先使用完整原始图像，或按原页对象范围重新以足够分辨率渲染。清晰度受原文件限制。边界不可靠时保留整页阅读。PDF 本身带有链接注释时，复用现有引擎读取页内目标或网址，重排后把点击范围关联到相同文字或对象。

先复用本地 PDF 渲染、端侧 OCR、原页映射和已有图片保存入口。下载前核对文件的导出限制与平台写入权限，保存成功后才提示成功。保存失败可留在预览重试。建议沿用图库的本机相册保存路径。实现回退以客户端改动为单位，仅重新生成对应资料版本的解析缓存。

## 五、导入书籍资料和封面

已有书从保留的原件修复。先分清正在导入的资料与其所属书籍，仅补全可确定、未手动设置的书目，保留用户选择的封面、显式清空的字段和资料显示名。旧记录缺乏编辑来源且有歧义时，交给现有确认表单。多版本书的出版信息分别取自对应原件。重复导入同一文件应复用资料，关联其他资料时保留原资料与已有任务。

本例按正式服落后一版安排。实施时复核设备实际访问地址和届时主分支的目标发行，从匹配远端主分支的干净工作区，使用 `xiaoqi_harness/deploy/deploy_current.ps1` 发布已通过检查的对应制品。只发布经过审查的同一发行，保留既有用户数据和单一紧急恢复点。若届时客户端也已落后，同步提供匹配构建。保留契约拒绝与两端版本提示，执行健康、契约、数据检查和失败回滚。

验收分两层。先验证匹配版本放行、不匹配版本能显示两端版本和恢复办法。再在匹配版本上从截图中的「网上找书」发起一次实际查询，核对版本选择、结果书卡、可导入文件、入库记录和伴读打开；无可导入结果时清楚说明原因。公共健康检查只能验证服务状态。

## 九、分层验收与回滚

| 验收场景 | 通过条件 |
| --- | --- |
| 原地往返、主动翻页 | 在任意 PDF 选一处段落、图片或表格，往返切换十次。每次回 PDF 都显示正确完整原页，回电子书仍在原处。然后在 PDF 主动翻到任意相邻页，切回电子书应从新页开头读。用不同 PDF 和页码覆盖水平分页及竖直阅读。 |
| 快速切换、预读、关闭重开 | 在转换未完成、邻页预读、改变字号时切换，最终页面只响应最后的操作。关闭后重开恢复到原文；仅有页号的旧记录能打开对应原页。用原录屏书页补查首次发生位置偏移的步骤。 |
| 标题与段落 | 逐项对照带编号的章、节、无编号小标题、普通段落和行内粗体。核对同一段跨两页、相邻两段跨页及图表前后的文字顺序，屏宽或字号变化后不吞段、不重复。 |
| 图表完整性 | 普通表、无框线表、配图带旁注的页和扫描页逐页对照。检查对象、表题、表注、数字及读序。宽表横滑到末列时页码不动，整页保留的样例也能点中正确图表。 |
| 下载与退出 | 在放大或横滑至半表时保存。打开实际文件核对边界、首末行列、小字清晰度及界面按钮未被存入。权限拒绝、保存失败及退出预览后，阅读位置正确。用读屏核对「下载」按钮名称。 |
