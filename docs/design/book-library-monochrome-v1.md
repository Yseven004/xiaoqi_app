## 已确认方向

### 书库首页与图标

- 采用封面优先的黑白界面；白色画布、原始书封、弱化书卡外框与阴影，用留白、文字层级和灰阶组织信息。
- 展示方式切换只保留顶栏一处；“全部书籍”工具行保留筛选、排序和多选管理，不重复放四宫格按钮。
- 多选管理用“勾选列表”语义图标，不用单个复选框或纸笔图标。
- 底部“笔记”图标直接复用主界面同一份 `assets/images/home_reply_note.svg`。保留主界面原按钮，独立笔记页面不改。
- 默认／选中／禁用／按下／焦点状态统一视觉字重和灰阶；真实书封与照片仍保留原有颜色。本轮已明确取消封面模板供给，不再提供模板选择。

### 共用添加弹窗

- 书库“新建”和主界面“阅读任务”使用同一个组件和样式，保留各入口原有的关联、返回及保存行为。
- 标题“添加到阅读空间”，下方仅两行操作：“导入资料／支持 PDF、EPUB”和“扫描 / 输入 ISBN／从实体书条码确认书籍资料”。
- 去掉操作行右侧箭头，去掉标题下方泛说明；保留两行必要的格式／用途提示。
- 白色贴底面板，从底部滑出，仅顶部圆角；覆盖底部导航，不做悬浮卡片。中性黑遮罩、灰色拖拽柄、右上关闭，不另加重复“取消”行。

### ISBN 扫描与手动输入

- 扫描页保留返回、闪光灯、条码取景、点按对焦和手动输入。白色取景角标、灰阶控件；相机真实画面不强制灰度化。
- 扫描页底部使用贴底白色操作区，“手动输入 ISBN”入口与必要隐私提示，取消暖色装饰。
- 手动输入面板贴底上滑，键盘打开时位于键盘上沿；黑色“查询书籍”按钮，黑灰输入边框。使用系统键盘，不自绘键盘。
- **打开手动输入必须真实停止扫描，同时将取景画面及扫描框整体模糊、压暗，明确表现扫描器当前未运行。输入面板与键盘保持清晰，背景不接收扫描操作。**
- 取消／关闭手动输入：退出输入焦点，恢复原扫描页及扫描；提交有效 ISBN：收键盘、进入原查询流程，扫描继续暂停。相机恢复失败仍保留手动输入路径。
- 全局焦点规则继续适用：空输入收键盘须失焦；有内容仅收键盘不强制失焦；按钮当次点击生效；输入框之间正常转移；禁止键盘动画重新抢焦点。主动进入手动输入属于明确输入任务。
- ISBN-10／ISBN-13 校验沿用现有逻辑，ISBN-10 末位 X 必须可通过系统输入／粘贴录入；不因视觉改版缩减输入能力。

### 书籍详情补充要求（2026-11-17 用户修订）

- 进入书籍详情后隐藏整条底部导航，包括分隔线与占位高度；不另加替代底栏。通过左上角或系统返回离开详情，恢复书库原导航及浏览状态。
- 删除详情正文中的“微信读书关联（可选）”区块及其说明。右上角“…”使用紧邻按钮下方的轻量下拉菜单，**不再使用底部操作面板**；菜单仅“编辑”“关联微信读书”“删除”三项，删除使用错误红。点击外部或系统返回关闭菜单，不操作背景内容，不使用整页深色遮罩。
- 分类并入“编辑”界面，和书籍资料一起修改、保存；从“…”菜单移除独立“调整分类”。保留最多 3 个分类的既有规则，取消编辑不提交分类草稿。
- 本书实际关联成功后，在书名附近显示小尺寸微信读书品牌图标；未关联、关联失败、仅从微信读书获取过封面或尚在准备中时不显示成功标记。不能以封面提供者或图片 URL 推断书籍已关联。
- 标记与书名留间距，长书名正常换行，提供“已关联微信读书”的语义说明；无需额外胶囊、提示长句或新按钮。
- **当前源码的关联入口仅展示未来服务说明，并无已验证的真实书籍关联能力。** 新图中的品牌标记及“已关联”仅展示未来成功态；本轮不据此伪造绑定数据、不宣称接入了授权或同步。现阶段菜单仍可展示准备中说明，真实能力接入须另行确认范围。
- 官方图标参考来自 [微信读书官网](https://weread.qq.com/) 的 [152×152 网站图标](https://rescdn.qqmail.com/node/wr/wrpage/style/images/independent/appleTouchIcon/apple-touch-icon-152x152.png)，2026-11-17 核对。小尺寸品牌标记保留原始图形；本地 PNG 仅用于概念参考，尚未取得官方 SVG，生产矢量资产仍待独立整理、预览和清单登记，不把该 PNG 当最终固定 UI 资产。

### 封面编辑精简（2026-11-17 用户修订）

- 删除全部封面模板供给、模板网格、“专属 AI 封面”及其占位、“使用自己的照片”重复入口、“应用此封面”按钮。
- “上传原书封面”改为“上传封面”，拍摄归入此入口；点击后选择“从相册选择”或“拍摄照片”，不在主编辑弹窗并列放置单独拍摄入口。
- “使用原书封面”改为**“恢复原书封面”**，作为恢复动作，不再做带勾选的列表选项。
- 旧的大型封面选择面板和第一版横向小预览加两行列表布局均被用户否定。最终七图已确认轻量居中弹窗：标题与关闭、居中竖向封面预览、下方并排“恢复原书封面”和“上传封面”，不重复书名／当前封面说明。
- 交互提案：恢复或选图／拍摄成功后返回调用方应用，不增加额外“应用”步骤；取消系统选择／拍摄不改原封面，失败保留原封面并允许重试。无原书封面时禁用恢复并说明原因，不能恢复成空白。
- 复用现有父级保存责任：详情页更换由详情保存；新建／编辑资料中的更换只更新该表单草稿，随表单保存，取消整个表单不提前写入书籍。图片权限拒绝和读取／保存失败均保留已有数据。
- 取消模板供给不等于删除用户既有封面；实现时先核对旧书籍对模板资源的引用，避免删资源造成现有封面丢失。本轮设计阶段不删除这些资源或改用户数据。
