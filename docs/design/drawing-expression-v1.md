# 绘图表达 V1

## 产品范围

用户从“技能 / 插件 → 绘图”打开画板，以手绘或图片标注表达需求；完成后加入聊天输入框，补充文字或直接发送。发送前可再次打开未发送的绘图附件；已发送图片保持为独立 PNG 快照。仅有绘图附件且没有用户文字时，消息构造器会附带理解意图、对象关系与标注的默认指令；有文字时以用户文字为主。所有模型均按支持识图处理，不添加模型能力判断或视觉辅助模型调用。

画板复用现有 Flutter Painter 绘图引擎。默认在可见的聊天界面上显示约 20% 遮罩和单张白色画板卡：竖屏约占屏宽 90%，比例 3:4；横屏比例 8:5，并在安全区域内自适应。只有点击输入框同款放大图标后才铺满安全区域，沿用 220ms `easeInOutCubic` 动画。返回手势直接放弃本次编辑；右下角“√”固定在卡片上，不随键盘上移。

顶部使用半透明玻璃工具胶囊，包含手绘、文字、图片、橡皮和颜色 / 笔尖粗细；撤回 / 重做在左，放大在右。胶囊以裁剪区外投影、半透明磨砂、亮色上缘与细微暗色下缘形成层次。颜色和橡皮弹层均紧凑横向、无指向角，受卡片宽度约束；极窄屏只滚动弹层内部选项。画笔直接进入绘制；文字首击只出现淡蓝虚线输入框，不自动呼出键盘，点输入框后才聚焦并打开多行键盘，点画布空白处插入文本。图片菜单提供拍照和上传；图片选择器及解码 / 插入期间，画布、焦点、工具和扩展操作均禁用，避免图片尚未实际插入时误触其他功能；成功插入后对象选中并可移动、等比缩放、旋转，点选后显示删除按钮；取消或失败后关闭来源弹层并恢复操作。橡皮提供三档粗细与清空操作，并显示半透明圆形擦除光标。对象选择框使用八个缩放点和位于图片下方的独立旋转控件，画布边界内变换。

返回系统手势不显示放弃确认框、不保存当前未完成修改；完成按钮负责保存并将 PNG 交给会话附件。旧草稿中的背景图片保持兼容，新图片插入为可编辑对象。

## 技术来源与取舍

- 绘图引擎：[Flutter Painter 2.1.0](https://pub.dev/packages/flutter_painter)，[源码](https://github.com/omarhurani/flutter_painter)，MIT。版本于 2026-07-29 发布；复用绘图对象、变换、历史记录与图片渲染，不另建绘图引擎。
- 选择框手势：[Box Transform](https://github.com/hyper-designed/box_transform)，固定提交 [`912492e67448ca7e5ac482a389a91b10836b8bbe`](https://github.com/hyper-designed/box_transform/commit/912492e67448ca7e5ac482a389a91b10836b8bbe)，Apache-2.0；复用 `flutter_box_transform` 的拖动、等比缩放和边界限制；为满足旋转控件位于对象下方的已确认交互，旋转角度由画板以对象中心的指针角度差更新。画布对象历史仍由 Flutter Painter 保存。此提交的 311 个纯 Dart 与 80 个 Flutter 上游测试此前已通过；本项目新增依赖锁定两个子包至同一提交。
- 画板工具图标：Lucide Icons 上游 SVG，MIT；来源、viewBox、尺寸和状态映射见 [技能 / 插件 V1 视觉资产清单](skills-plugins-v1-asset-catalog.md) 及 64×64 [图标预览](../../assets/icons/drawing/icon-preview.html)。其余图标复用项目既有 SVG。
- 草稿保存在应用支持目录，使用账号范围摘要与会话 ID 分区；画布场景 JSON 与底图副本单独持久化，以临时文件和替换文件保存。发送附件另存为白底 PNG，不复用可变草稿文件。
- 沿用现有附件消息构造器，将绘图 PNG 编码为 `image_url` 内容；没有后端 API 或服务部署变更。
- PNG 最长边不超过 2048 像素，超过 5 MB 时按比例逐级降低分辨率，仍超限则保留草稿并提示重试。
