# 绘图表达 V1

## 产品范围

用户从“技能 / 插件 → 绘图”打开画板，以手绘或图片标注表达需求；完成后加入聊天输入框，补充文字或直接发送。发送前可再次打开未发送的绘图附件；已发送图片保持为独立 PNG 快照。仅有绘图附件且没有用户文字时，消息构造器会附带理解意图、对象关系与标注的默认指令；有文字时以用户文字为主。所有模型均按支持识图处理，不添加模型能力判断或视觉辅助模型调用。

画板复用现有 Flutter Painter 绘图引擎。手机使用全屏画板，较宽屏幕使用居中 4:5 白色画布；工具栏提供选择、手绘、文字、箭头、矩形、圆形、橡皮擦、撤销 / 重做，侧边调节线宽，底部提供颜色与图片导入、完成操作。导入图片只作为锁定底图，标注不改原文件。

## 技术来源与取舍

- 绘图引擎：[Flutter Painter 2.1.0](https://pub.dev/packages/flutter_painter)，[源码](https://github.com/omarhurani/flutter_painter)，MIT。版本于 2026-07-29 发布；复用绘图对象、变换、历史记录与图片渲染，不另建绘图引擎。
- 画板工具图标：Lucide Icons 上游 SVG，MIT；来源、viewBox、尺寸和状态映射见 [技能 / 插件 V1 视觉资产清单](skills-plugins-v1-asset-catalog.md) 及 64×64 [图标预览](../../assets/icons/drawing/icon-preview.html)。其余图标复用项目既有 SVG。
- 草稿保存在应用支持目录，使用账号范围摘要与会话 ID 分区；画布场景 JSON 与底图副本单独持久化，以临时文件和替换文件保存。发送附件另存为白底 PNG，不复用可变草稿文件。
- 沿用现有附件消息构造器，将绘图 PNG 编码为 `image_url` 内容；没有后端 API 或服务部署变更。
- PNG 最长边不超过 2048 像素，超过 5 MB 时按比例逐级降低分辨率，仍超限则保留草稿并提示重试。
