# 扩展市场 V1 Layout Spec

状态：按已确认的平板目标图整理，作为 Flutter 接入规格；实际渲染仍需同 viewport 视觉验收。

## 目标与边界

- 目标图：`market-tablet-approved.png`、`detail-tablet-approved.png`
- 画布：1048 × 1501，竖屏；目标图不包含系统状态栏
- 适配：以内容宽度为基准，平板保持两列，窄屏折叠为一列；不以截图像素直接充当所有 dp
- 未冻结：作者独立详情页视觉稿；V1 先显示个人作者空作品状态

## 市场页

| 区域 | 目标关系 | Flutter 约束 |
|---|---|---|
| 页面边距 | 左右约 40，顶部约 22 | `Padding(horizontal: 40)`；窄屏降至 20 |
| 顶栏 | 返回图标、标题、创建/导入按钮同一行 | 高度约 62；按钮宽约 184、高约 60、圆角 20 |
| 搜索 | 顶栏下方 24；满宽浅灰表面 | 高约 74，圆角 16；搜索图标 32 |
| 一级页签 | 搜索下方约 34；技能/插件/MCP 等宽 | 高约 76；选中下划线约 4 |
| 二级筛选 | 页签下方约 23；胶囊高约 54 | 选中黑底白字；未选中浅灰底 |
| 精选合集 | 标题、单张横幅轮播、5 圆点 | 卡片高约 220，圆角 14；每次只显示一张满宽横幅，5 圆点置于卡片内右下角，无左右箭头 |
| 条目分区 | 标题整行可点；条目两列 | 列间距 16；卡片等高约 122；窄屏一列 |
| 条目卡片 | 图标、名称、作者、简介、独立安装控件 | 平板卡片等高约 122；图标约 78；右侧居中显示无外圈“＋/✓”（图标约 28，点击热区 48）；主体和安装控件分离点击 |

## 详情页

| 区域 | 目标关系 | Flutter 约束 |
|---|---|---|
| 顶栏 | 返回、标题 | 高度约 68；不使用路由转圈加载 |
| 信息头 | 140 左右图标 + 信息 + 右侧安装 | 宽屏 Row；窄屏自然换行；作者名、跳转箭头与类型标签同一行；作者区与仓库区可点击 |
| 简要说明 | 版本/仓库行下方 | 宽屏左边缘与版本行对齐，不与大图标左边缘对齐；适用内容仍为独立一行 |
| 适用内容 | 标题区下方独立一行 | 设备图标与浅灰正文对齐 |
| 功能说明 | 标题、说明、横向可滚动图文卡片 | 首卡约 56% 宽，其余约 40% 宽；点击配图打开预览；不显示扩展按钮或分页圆点 |
| 使用方式 | 标题、说明、纯文本编号示例 | 长文本自然换行，不做按钮卡片 |

## 状态矩阵

| 状态 | 市场页 | 详情页 | 说明 |
|---|---|---|---|
| 默认 | 精选/技能/未安装 | 可安装 | 默认首条“论文精读”用于演示 |
| 已安装 | “＋”变“✓” | 安装按钮变“已安装” | 点击主体仍进入详情 |
| 搜索 | 过滤条目与分类 | 不改变详情内容 | 无结果显示静态空状态 |
| 我创建的 | 空状态 | 作者页作品暂为空 | 本版本不接入个人发布作品数据 |
| 执行中 | 不用路由 spinner | 按钮内小反馈可保留 | 本 UI 版本不实现网络安装任务 |
| 错误 | 静态错误文案/重试入口预留 | 静态错误文案/重试入口预留 | 不使用 CircularProgressIndicator 过渡 |
