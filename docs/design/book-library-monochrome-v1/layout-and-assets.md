# 书库黑白重设计：布局规格与图标清单

更新：2026-11-17。依据用户确认的七张概念图、现有书库实现和 DESIGN.md。

## 已测参考尺寸

reference-49 至 reference-54 均为 965×1629／1630 px；reference-55 为 1487×1058 px。原始录屏为 720×1152 视频。上述是图片像素，不是 Flutter 逻辑尺寸。目标 Android viewport、DPR、安全区、字体比例与 IME 高度仍待设备测量，不能把这些像素直接转成 dp。

| 区域 | 层级与响应规则 | 未知测量／状态 |
| --- | --- | --- |
| 书库顶栏（49） | 左侧标题与真实书数；右侧单处网格／列表切换和新建主操作；紧凑宽度不挤掉主操作 | 横边距、高度待测；默认、按下、键盘、长标题 |
| 搜索（49） | 全内容宽，置于顶栏下方；窄屏不与工具挤在一行 | 高度、间距待测；空、输入、无结果、清除、失焦 |
| 分类与工具（49） | 全部书籍靠左，筛选、排序、多选靠右；触控至少 48dp，窄宽度可换行 | 间距待测；已筛选、升／降序、多选状态 |
| 书籍网格（49） | 封面主导，真实书名和统计置于封面下；弱化边框阴影 | 列数按可用宽响应，封面保持原比例；空库、无结果、缺封面、选中 |
| 添加面板（50） | 白色贴底，上圆角；顶部拖柄；标题与关闭；两行操作及细线分隔 | 安全区适配；打开、按下、关闭、系统返回 |
| ISBN 扫描（51） | 返回、标题、闪光灯，真实取景和角标，底部手动输入入口 | 按相机比例适配；加载、运行、权限拒绝、失败、识别结果 |
| 手动 ISBN（52） | 标题与关闭、输入、黑色查询按钮，沿用系统键盘 | 面板跟随 IME，窄屏可滚动；打开时取景整体模糊压暗且扫描停止；空、无效、查询、失败 |
| 详情（53／54） | 返回、分享、更多；书封和资料；真实统计；简介；笔记；完全隐藏底栏 | 窄屏纵向阅读，大屏使用可读内容列；静态占位、错误、长简介、空／非空笔记 |
| 详情菜单（53） | 锚定三个点下方，仅编辑、关联微信读书、删除 | 屏幕边界内定位；外部点关闭且不穿透；系统返回关闭 |
| 编辑封面（54） | 居中白色轻量弹窗；标题、关闭、竖向预览、并排恢复／上传 | 最大宽度待测；有原封面、无原封面、来源菜单、取消、拒绝、失败 |
| 笔记空态 | 保留详情页现有文字提示和点击行为 | 原有位置与显示条件不变；本轮不改视觉或引导操作 |

手机上搜索、工具和书卡随可用宽度纵向重排；平板按可用宽度增列并扩展详情内容列。两种尺寸都需保留 48dp 触控区、安全区和系统返回行为。字体增大时标题、书名和操作允许换行，不裁主操作。

| 图形 | 来源和路径 | viewBox／尺寸 | 状态与消费组件 | 预览 |
| --- | --- | --- | --- | --- |
| 纸笔笔记图标 | 复用 `assets/images/home_reply_note.svg` | viewBox `0 0 24 24`；BookLearningBottomBar 显示 27×27 dp | 默认灰、选中黑；`BookLearningBottomBar` | [bottom-note-icon-96.png](previews/bottom-note-icon-96.png)，独立 27×27 状态预览；原资产保持不改 |
| 网格／列表、筛选、排序、多选、添加、ISBN、返回、分享、编辑、删除、相机 | 优先搜现有 SVG 和已安装 Phosphor 组件；缺失才取 Phosphor 原始 SVG（MIT），记录实际 tag／来源 | 沿用源 viewBox；触控盒最少 48dp | 单一线性图标系列；激活和错误色由 DESIGN.md 及真实状态决定 | 每个实际选定资产在 64×64 或实用显示尺寸独立预览；图形与许可证待逐项登记 |

封面照片、书籍封面保持真实栅格图。以上不把概念截图裁片当生产图标。笔记空态保留原文字和行为，不新建插画。其余未改变的 Material 控件图标沿用 Flutter 的平台图标组件；本次变更新增或复用的固定图形须登记来源、许可、独立预览、viewBox 与显示尺寸。

## 主题消费者与历史封面保留范围

`BookFlowTheme` 同时服务书库、ISBN 扫描、候选确认、资料表单、封面选择、书籍详情、来源与阅读器、发现页、阅读任务创建和笔记页。黑白改造仅在本计划明示的页面和弹窗局部应用；不得改共享主题令牌或清理被其他页面使用的消费者。`book_sources_page.dart` 与 `book_page_reader_page.dart` 使用详情暖色令牌，继续原样保留。

旧封面模板是已保存书籍的持久化数据，不是可删除的临时素材。`BookCoverTemplateDefinition.values` 当前有 `healing`、`healing_meadow`、`healing_cove`、`healing_birch`、`animation`、`animation_bicycle`、`animation_train`、`animation_window`、`line`、`line_cafe`、`line_balcony`、`line_desk` 十二种 ID；`books.cover_template` 保存模板 ID，`BookCover` 仍负责历史模板渲染，`BookCoverStorage.persistCatalogueCover` 保留 `coverType == 'template'` 数据。P4 只停止提供新的模板选择，保留这些定义、图片资源、字段默认值及渲染兼容，不批量重写旧书封面。
