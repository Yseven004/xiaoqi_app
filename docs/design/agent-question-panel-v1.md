# Agent 提问面板：第一张方向细化

日期：2026-11-15。状态：**用户已确认第一张方向、细化图及以下交互，作为本次修复的冻结设计补充。** 已按本文接入 GenUI Surface 与 A2UI 交互；键盘和真机表现仍待用户验收。

## 已确认的视觉和位置

- 使用项目 DESIGN.md 的黑白灰、系统无衬线字体、浅色细边框与轻浮层阴影。沿用第一张的纵向选项列表，不扩展为整个聊天页重设计。
- 未编辑时，面板位于聊天输入区域上方，不遮暗页面。底部始终保留自定义回答入口，选项与文字输入使用同一套视觉规范。
- 顶部显示问题与题号，提供前后题切换；底部保留取消任务与当前推进操作。第一题不能上一题，最后一题显示“提交并继续”；单题不显示多题导航。

## 多题和回答状态

- 切换题目保留各题的选项、自定义文本和当前使用的回答方式；切换不向 Agent 提交、不重新生成问题。
- 预设选项与自定义文字一起交给 AI 理解，由 AI 判断文字是补充还是修改；前端分别保留两者，不能输入文字就清空选项，也不能选择选项就清空文字。废止此前“自定义内容自动替代预设答案”的设计假设。
- 单选题选中后，有下一题则直接切到下一题；最后一道题选完仍保留卡片，必须点击“提交并继续”才提交。多选题选中后留在当前题，通过“下一题”切换。
- 可自由前后切题，当前题未回答也不阻拦；题目数量、单选/多选及必填条件来自实际问题定义，不由 UI 猜测。底部自定义输入支持多行，键盘回车仅换行，不切题、不提交。
- “下一题”只推进题目，最终提交统一校验所有必答题，未填时定位对应题目并给出就地提示，不丢失其他答案。明确点击最终提交才恢复 Agent；处理中阻止重复提交，失败保留全部答案并支持重试。

## 键盘、遮罩与焦点

- 面板首次出现、暂停后返回时不自动聚焦、不自动弹键盘。键盘原本隐藏时，切题不弹键盘；键盘原本可见时，选择选项并切题保持键盘展开，不先收起再弹出。
- 键盘弹出时按真实键盘 inset 同步调整面板位置，面板底部位于键盘上方，间隙建议 8–12dp；不根据机型写死键盘高度，不叠加两次避让。
- **只有系统键盘和提问卡片随键盘上下移动。** 顶栏、消息画布、原聊天输入框、能力工具条等其他组件不跟随、不被整体顶起；底部内容可被键盘及遮罩覆盖。宿主整体 resize 不能造成第二次布局上移或聊天滚动。
- 编辑期间其余页面由半透明黑色遮罩覆盖，包括原聊天输入区；原页面不可穿透点击。面板和键盘保持可操作，原聊天输入框不能接管此次回答。
- 本面板遵守用户本次更具体的焦点要求：用户主动收起键盘时，**无论文本是否为空，立即退出当前输入焦点，移除光标与焦点边框，保留全部已填内容**。这项规则仅覆盖本提问面板，不更改其他输入框“有内容时仅收键盘可保留焦点”的全局默认。
- 点击遮罩仅收键盘并失焦，不提交、不取消任务、不关闭问题面板；收起后遮罩消失，面板回到聊天输入区上方。系统返回键在键盘可见时先结束编辑，不等同于取消任务。
- 点击选项、上一题、下一题在当次点击执行；键盘已展开时保持展开，切题时把编辑目标正确绑定到新题的自定义输入，不能串写答案。此处是用户明确要求的面板局部交互，不套用点击任意按钮先收键盘的通用做法。键盘隐藏时不主动聚焦；明确点击其他输入控件时正常转移焦点。
- 点击最终提交或取消任务均收键盘并失焦，当次执行对应操作，不要求第二次点击；最终提交失败保留各题答案，不自动重新聚焦。点击空白遮罩只收键盘、失焦，不取消任务。
- 键盘动画、窗口尺寸变化、面板重建、回答流更新不允许重新抢焦点；键盘高度暂时变化不能误判成用户收起。无障碍明确聚焦继续可用。
- 键盘收起时的回落使用同一布局基准，避免最后一帧跳动；保留原聊天的阅读位置。

## 取消、暂停返回和恢复

| 操作 | 确认行为 |
| --- | --- |
| 点击“取消任务” | 收起键盘、退出焦点，终止当前任务并关闭提问卡片；取消后的任务不提供“继续”入口，不转成暂停 |
| 键盘展开时按系统返回 | 先收起键盘并失焦，卡片仍在；不把收键盘误判成退出页面或取消任务 |
| 键盘已收起时按系统返回离开 | 暂停当前任务，保留卡片、当前题号、全部选项和自定义答案，并返回上一页；不弹“是否取消任务”的确认框 |
| 再进入该会话 | 显示原卡片和已填答案，保持暂停，不自动恢复、不自动提交、不弹键盘；明确显示“继续任务”入口 |
| 点击“继续任务” | 按原任务/原中断恢复并回到可回答状态；保留原题目与草稿，未最终提交的答案不自动发给模型 |

暂停需落实到官方取消/快照和原工具中断，不可只改 UI 状态。取消是终止语义：不得保留可恢复入口或让迟到的工具回调、卡片动作重新启动任务；已完成的外部操作不因关闭卡片被自动撤销。上述系统返回规则针对本提问面板，不改变原方案中普通切换会话/返回书库时任务继续的默认行为。

## 提交后的对话记录

- 提交成功后收起浮层，在对话内保留一条默认折叠的问答摘要，采用 Codex 类似的展开/收起交互。
- 展开显示本轮实际问题、所选答案和自定义文字；多道题按原顺序展示。展开仅阅读，不重新提交、不重新启动任务。
- 提交失败时不生成“已提交”摘要、不关闭表单；保留答案并给出重试反馈。同一次提交重试不能重复写摘要或恢复工具。
- 摘要与原会话、分支、任务和提问身份关联；草稿与已提交记录区分保存，不能混入其他分支。保存用户答案是业务数据适配，不创建第二份模型历史或自定义 Agent 调度器。

## 小屏、平板与长内容

- 根据安全区和可用窗口高度约束面板。长题干、多选项或大字体时，中间内容可滚动，问题导航与自定义输入、提交操作仍可达；不让卡片顶出屏幕。
- 自定义输入高度有上限，长文本内部滚动；不能无限挤压选项。触控目标至少 48dp，焦点、选中状态不只依赖颜色表达。
- 平板面板对齐聊天输入区域并限制阅读宽度，不拉伸到整屏。分屏与浮动键盘按实际遮挡处理，不将“输入焦点存在”简单等同于底部键盘一定可见。

## 框架边界与待实施项

- 本文定义的是 Flutter 宿主面板的外观、键盘避让与焦点规则。A2UI 的数据绑定、Surface 生命周期及 action 事件继续走经版本核验的官方能力；真实工具提问通过官方中断恢复入口，不能把两种机制混为一个自造状态机。
- 问题数量、选项、必填条件来自实际工具或 Catalog 定义；概念图里的两道题只是示例，不将题数写死。
- 代码已实现键盘跟随、题目草稿、遮罩、焦点退出和 Agent 中断续接；概念图不能证明实际运行效果，仍待用户真机验证。
