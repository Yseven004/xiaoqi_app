# 生图动效、对话跟随与协议边界修复 V2

确认来源：用户 2026-10-19 提供的视频一（43.93 秒）、DeepSeek 参考视频二（28.49 秒）及 A2UI/DSML 异常截图。保留上一版已确认的蓝、紫、青配色、3:4 比例、480 dp 最大宽度和 14 dp 圆角。

## 已定位问题与本次范围

1. 原光晕周期 22 秒、中心移动幅度小，动态叠层与底色接近；网格 SVG 的 0.34 透明度又乘以组件 0.42，实际只有 0.1428。改为 10 秒闭合流动、5 秒柔和呼吸，加大同色系层的位移与明暗变化；保持网格静止、细小且可辨，不闪烁。
2. 对话内容高度变化只触发溢出测量，没有触发自动跟随。新增内容尺寸通知驱动的平滑跟随（420 ms），合并动画期间的变化；用户主动上翻立即停止跟随，返回底部后恢复。减少动态效果模式使用静态渐变和即时位置更新。
3. 已安装的自动发现技能阻止了显式“创建图像”的直接路由。明确动作、输入非空且无需先交付文字解释时直接使用图片服务；显式选中的扩展仍遵守原执行流程，空输入仍询问图片内容，解释并配图的混合任务保留原流程。
4. 最终回答仍带工具执行提示、历史工具调用，并挂载 A2UI。最终阶段保留工具定义以避免 DeepSeek 的空工具目录协议异常，但以原生 `tool_choice: none` 禁用执行；移除该阶段 A2UI，明确只输出最终正文。必要澄清只发生在准备阶段。
5. 在流式文本出口阻断完整及跨 chunk 的 DSML 控制序列；异常响应不能当作成功正文保存。重试只针对尚未发布正文的模型格式错误，不重试已发起的生图请求。
