# 平板伴读 · 选段问答

## 2026-11-22 · 沉浸阅读、连续翻译与涂鸦

- 「沉浸伴读」沿用内置插件开关和阅读空间入口。目录、进度、显示、格式切换、选文、涂鸦、翻译由插件直接调用。自由问答和选段问答复用现有 Genkit 会话，不向 Agent 注册阅读界面操作。
- 阅读态轻点正文显隐工具栏，沉浸态保留弱化的位置标记。同书 PDF 与电子书各自保存续读位置。底栏三项等宽，目录显示当前位置，进度可回到跳转前的位置。电子书默认正文约占屏宽 92%。显示设置遵循应用级亮度作用域，离开阅读器恢复系统亮度。键盘与输入焦点遵循 [全局设计规范](../../DESIGN.md)。
- PDF 依靠锁定的 pdfrx 2.4.8 公开扩展接主界面选区手柄和操作卡，保留文件复制权限。深色模式仅在本地预览确认黑白时转换页面，彩色或未确定时保留原色。电子书排版继续由 Flutter 3.47.5 和既有文档组件负责。[pdfrx 2.4.8（MIT）](https://pub.dev/packages/pdfrx/versions/2.4.8) · [Flutter 3.47.5（BSD-3-Clause）](https://github.com/flutter/flutter/blob/3.47.5/LICENSE)
- 原文与译文的涂鸦分别按资料版本及页或文段保存，电子书或译文重排后可从文段标记回看旧版。笔迹复用现有 PageStroke 和笔记编辑器的曲线几何。文字注释仍进现有笔记，连同原始位置和引用版本一起保存。
- 首次打开翻译前明确告知正文会发送给 DeepSeek。之后随翻页或浏览推进自动翻译，按资料记住原文和译文状态。有选区或正在涂鸦时延后替换。启动时保持原文，结果失败可重试，过期结果不覆盖当前页。初期验证英、日、韩译简中，自托管候选是 LibreTranslate v1.9.6，暂不纳入发布。[LibreTranslate v1.9.6（AGPL-3.0）](https://github.com/LibreTranslate/LibreTranslate/releases/tag/v1.9.6)

## 2026-11-21 · 自由问答与选段问答

- 在伴读侧栏点「新建会话」开始当前书和资料的自由问答。选中原文后点「AI」打开该段的问答，追问继续沿用这段引文。两个入口各自创建会话，首次发出提问后才出现在历史中。
- 同一本书的「对话记录」合并展示两类问答，最近打开或提问的排在前面。自由问答显示标题，选段问答在标题下多显示一行原文，超长时省略。重新打开选段记录时，问答卡和后续提问均使用这条记录保存的引文。
- Flutter 本地会话沿用已有的用户消息及选段字段，兼容旧记录。最近打开时间由本地历史服务维护，Genkit Dart 1.0.2 的会话执行、快照和分支继续复用原接口。验证两个入口的首问、混排、引文显示及重开后的追问，回滚范围为 Flutter 客户端。
- 列表沿用现有侧栏行，参考项目锁定 Flutter 3.47.5 的单行副标题规则，核对日期为 2026-11-21。[Flutter 列表副标题](https://api.flutter.dev/flutter/material/ListTile/subtitle.html) · [Flutter 源码（BSD-3-Clause）](https://github.com/flutter/flutter/blob/master/packages/flutter/lib/src/material/list_tile.dart)
- 本轮 19 项 Flutter 定向测试通过。实际组件覆盖选段与自由问答分别发送首问、未发送草稿、重开后追问、混排和 320dp 宽且字号 200% 时的单行摘录。转场测试记录到进入后第 300 毫秒两页仍在移动，完成时归位，系统减少动态效果时首帧直接到位。真机滑动手感待验收。

## 2026-11-21 · 伴读入口与阅读空间侧边栏

- 主界面和伴读共用阅读空间顶栏。进入时主界面向左、伴读从右侧同步滑入，用 420 毫秒缓进缓出。主动返回时反向滑动，用 260 毫秒。打开和收起侧边栏均保留当前模式、阅读位置及问答状态。系统减少动态效果时直接切换。
- 用户点伴读时，当前阅读任务只有一份可用资料就打开该份，有多份时打开任务已选的那份。没有明确目标时留在主界面，居中显示「当前未在“阅读任务”选中目标资料，请先选择相应资料」，一秒后淡出。
- 两个模式都通过侧栏书名选中对应阅读任务，书名旁的展开控件继续显示该书的对话记录。普通模式列出普通对话，伴读模式列出伴读对话，侧栏搜索使用当前模式的记录。点伴读记录在阅读器里的问答窗继续该对话。
- 在伴读中换书，目标资料明确即可切换。需要选择时在原阅读页上打开目标书的关联资料卡；选好后切换，关闭卡片则保留原书、原任务和原阅读位置。没有资料时可以使用卡片已有的导入入口。
- Flutter 客户端负责阅读模式、资料选择和本地历史归类。新伴读记录保存来源资料 ID，旧记录用已有的选段字段识别。双端锁定的 Genkit Dart 1.0.2 继续由 `remoteAgent` 与 `SessionRunner` 处理会话执行、快照和分支。本次只扩展客户端展示所需的本地信息。
- 转场复用项目锁定 Flutter 3.47.5 的平移动画及现有顶栏和侧栏，只在进入伴读时装载阅读器。技术参考为 [Flutter SlideTransition](https://api.flutter.dev/flutter/widgets/SlideTransition-class.html) 和 [Flutter 工程及 BSD-3-Clause 许可证](https://github.com/flutter/flutter/blob/master/LICENSE)，核对日期为 2026-11-21。
- 验收分别检查未选资料、唯一资料、多份待选、切书取消、两种历史筛选及搜索、回到原页和草稿恢复。滑动过程和大文件首屏耗时需在目标设备验证。回滚客户端改动即可恢复原展示，历史仍使用原有会话存储。
- 验证记录：Flutter 定向测试 17 项通过，包含实际点选书名、取消或确认资料、两种侧栏历史及搜索、旧引文恢复、转场中页面位移和 PDF 页码恢复。旧资料无法定位时可继续查看原问答。额外书库回归中两项网上找书文案断言在改动前的提交 `134a6fd` 也失败。尚未执行真机帧率及大文件首屏测量。

## 「＋」展开后的交互要求

- 一级菜单在「＋」按钮正上方弹出。三个入口从上到下依次是「文件」「技能 / 插件」「MCP 连接器」，每行图标在左、名称在右。「文件」使用用户提供的回形针样式，另两项复用首页的 `skill_plugin_capsule.svg` 和 `mcp_connector.svg`。
- 点任一入口，同一次点按即收起一级菜单，并在伴读输入框正上方展开该类别的选择卡。选择卡位于伴读窗内，下沿贴近输入框上沿，输入框保持可见且位置固定。三个入口共用这个位置，每次只显示一张卡。关闭选择卡后回到同一段问答，保留输入草稿。
- 三张子卡与输入框等宽，下沿对齐在输入框上方。在 900 × 1350 的平板参考画布中，卡宽 504，距输入框 8。高度由可见内容撑开，最后一行下面只保留常规内边距。文件卡按三个来源自然收高。技能 / 插件卡和 MCP 卡分别受各自上限及可用空间约束，前者允许展示更多内容。
- 列表超出上限时，仅列表区上下滚动。标题、关闭按钮和输入框保持原位，背景对话保留原滚动位置。技能 / 插件卡顶部的「创建图像」「绘图」也保持可见。
- 三张选择卡的列表项均可整行点按，统一去掉行末的右箭头「›」。
- 「文件」列出图片、本地文件和微信文件三个来源。点「图片」可以从相册选择或拍照。
- 「创建图像」和「绘图」是常驻入口。任何安装状态下都可以直接点按，两项操作与下面的可安装内容分开。已安装条目按「技能」「插件」分区展示。只有一类为空时，在该区给出去安装的入口；两类都为空时，在常驻入口下合并为一行提示「还没有安装技能或插件」，点「去安装」进入市场。
- 「MCP 连接器」列出本轮可用的连接器。尚未安装或添加任何连接器时，点「去安装连接器」进入插件市场内可安装的 MCP 目录。已添加但暂不可用时引导用户管理现有连接。读取失败时提供重试，保留已有条目。
