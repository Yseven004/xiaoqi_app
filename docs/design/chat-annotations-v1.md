- 「标注 / 注释」切换只同步切换当前画布的工具与点位输入，不在切换时卸载画布、重置缩放或等待图像导出；离开标注时的图像快照在后台生成。预览在两种模式间保持同一键盘避让策略，并隔离绘图层重绘。顶部完成/退出提示栏仅在注释模式显示，空状态提示为“点击图片以添加注释点位”。
- 图片点位与文字锚点的“添加可选评论…”输入框贴近对应点位显示，创建时不自动聚焦；点按后才打开键盘。键盘出现时主聊天输入区保持原位，评论框仅在会被键盘遮住时向上让位。新点位评论为空时，点图片外空白或其他模式按钮退出注释模式。
- AI 回复文字菜单为「做笔记 / 注释 / 复制」，自己的消息保留「修改 / 复制」。选中原文可附加可选评论，输入框以条数入口汇总，可编辑、移除；“注释”汇总气泡右上角的“×”直接清空待发送注释；只点完成不直接发送 AI。回复文本的蓝色点位使用待发送注释中的连续序号，不在每条回复中重新从 1 开始。

## 数据与状态

文字注释草稿按账号摘要与会话 ID 单独保存；图片批注绑定对应附件，原图、工作副本、供 AI 读取的带编号快照分别保存。图片注释修改后将“快照待更新”状态与附件一起持久化，重启后发送前仍会重新生成正确快照。文字锚点保留选区范围、原文及来源回复摘要，以实际排版重新定位；来源变化时仅保留引用。发送时展开为原文引用、图片名称与归一化坐标以及用户评论，沿用现有附件 API，不增加服务器协议或上传本地编辑元数据。

发送后清空输入框注释，失败恢复待发送引用与相关附件；历史消息保留本次引用文本。顶部完成汇总本组所有已修改图片；超出 9 个附件时不部分提交，保存失败保留编辑现场。退出未完成预览需确认放弃，保留此前输入框中的版本。无路由转圈加载态，图片加载使用静态占位与错误重试。下载始终保存原始文件，不包含绘图、编号、输入框或工具栏；用户取消保存不显示成功。

新增本地数据可随功能回退被忽略；不迁移或覆写历史消息/原图。相关代码与文档可独立回退；服务端部署不需要，原因是没有运行服务或 API 合约变更。
