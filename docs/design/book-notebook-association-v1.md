- 目标图：用户 `codex-clipboard-40616205-42fd-43d3-a40f-53ff5cc32c2f.png` 的横向排列、尺寸；标题按 `codex-clipboard-36ada658-56e4-4f97-a467-4b5b0b89a93a.png` 放在封面内，下方只显示笔记数。用户已明确允许直接开工，不再重做候选。

- 单色系封面沿用现有 NotebookTheme 颜色选择，不引入图片封面。复用现有书籍外形、左侧书脊、圆角与折线效果，不使用生成图裁片。

- 移动笔记时主要书籍随目标笔记本变化，移入默认本取消自动关联；手动补充引用保留。编辑已有笔记保留原笔记本。长按普通笔记本复用新增弹窗，标题“编辑笔记本”，预填名称和颜色。

## 数据与研究

SQLite v33→v34：笔记本新增稳定 book_id、is_default；补充引用用 is_manual 区分人工引用与自动主要来源。只增字段和索引，不删除历史笔记、附件、Quill Delta 或聊天来源。不按同名推断旧笔记本归属；历史未绑定笔记本可通过现有笔记移动流程整理。迁移中默认本按原默认名称优先、最早 ID 兜底确定一次，后续使用标记而不是名称。默认本不可归档或删除，以维持唯一全局入口。

书籍详情包含直接绑定本书的笔记本，以及其中笔记通过真实书籍 ID 引用本书的非默认笔记本；不会仅因名称相同就展示。全局默认本始终不进入书籍详情；历史在默认本中的旧书籍笔记仍保留在总面板，可移动到关联本后整理。引用共享本展示整本笔记数，点击打开该本完整列表。

沿用现有 Memos 关系存取适配与项目 SQLite 事务。新增/保存笔记、创建自动本及更新主要来源在同一事务中提交，失败回滚；移动同样保持原子性。

一手参考：[SQLite Transaction](https://www.sqlite.org/lang_transaction.html)（2026-10-20 已读取）。本次未复制外部代码，不新增运行时依赖。回滚通过恢复升级前本地数据库备份或前滚修复；不提供旧客户端写入 v34 的兼容层，不在应用打开时执行降级。
