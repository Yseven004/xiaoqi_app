# 笔记面板统一：2026-10-20 确认范围

## 用户确认的目标

2026-10-21 补充：书籍归属、全局默认本、长按编辑及书籍详情笔记本展示以 [book-notebook-association-v1.md](book-notebook-association-v1.md) 为最新已确认规格。本文件“仅 UI、不改表结构”仅描述此前的面板统一任务，不包含本次 v34 本地迁移。

- 对话右上角“笔记”直接显示 `AddChatNoteSheet` 面板，不再进入另一套管理列表。
- 原“做笔记”选择流程、笔记本切换及新建、聊天来源和自动保存沿用现有逻辑。
- 面板标题右侧增加回收站和展开操作；不保留标题栏新建“+”。新建只保留右下角黑底白“+”。
- 展开按钮复用输入框 `home_composer_expand.svg`，展开/收起沿用 220ms、easeInOutCubic，并尊重减少动态效果设置。
- 面板上拉可展开，展开后下拉可收起；列表滚动参与原生拖动，不重建列表或丢失筛选/滚动位置。
- 书库底部“笔记”直接显示同一面板的展开状态，保留底部导航。
- 编辑器沿用用户图四；顶部遵守系统安全区，返回前保存，保存失败保留编辑现场。

| 项目 | 约束 |

| 编辑器 | 顶部由 SafeArea 避让状态栏；保留图四的工具栏、正文及键盘交互 |

## 状态与验收边界

- 静态占位、读取失败重试、空列表、笔记本筛选、新建取消、保存失败、回收站恢复后刷新。
- 展开/收起、上拉/下拉、长列表滚动、返回关闭面板、返回聊天保留草稿及滚动。
- 既有置顶/删除/来源与引用操作保留在笔记操作菜单，不再维持另一套管理列表。
- 搜索通过“所有笔记”右侧按钮展开；移动/置顶/删除及来源引用通过每篇笔记操作菜单或长按进入。编辑器“添加”面板继续提供笔记引用选择。
- 仅 Flutter UI；不改变本地表结构、服务端或 API。
- 未执行本地分析、测试、构建、渲染或真机操作；待用户验证。

代码接入完成：对话及选文入口已汇合到同一面板，书库展开状态共用列表实例；回收站恢复后刷新；编辑器顶部 SafeArea 和返回前等待保存已接入。仅执行源码核对与格式整理，不将它们视为静态分析或交互验收。

用户验收顺序：对话右上角打开面板 → 顶部上拉展开 → 下拉收起 → 新建并输入后返回 → 回收站恢复一篇笔记 → 书库底部“笔记”查看直接展开状态。再核对图四编辑器顶部、键盘、大字体及长列表滚动。
