# 小七笔记管理 V1：设计评审与实施边界

日期：2026-10-20

状态：2026-10-20 用户进一步确认统一使用原“添加到笔记”面板，替换独立管理列表；对话入口弹出可展开面板，书库“笔记”直接展示展开版。最新规格见 [笔记面板统一](note-panel-unification-v1.md)。本轮代码已接入，未执行验证，待用户真机验证。

## 已确认范围

1. 本机 SQLite 保存主数据。全部笔记列表作为首页，支持搜索、按笔记本和书籍筛选、新建、移动、置顶和回收。
2. 对话页右上角常驻“笔记”图标；已有消息时与“新建会话”并排。点击后弹出统一笔记面板，按钮或上拉均可展开；底部“笔记”直接使用同一面板的展开状态。返回保留对话、草稿和滚动位置。
3. 一篇笔记最多一个主要来源，可引用多本书籍。选择笔记插入正文引用，自动显示反向链接，以 ID 定位而非标题。
4. 删除书籍与专属笔记进入 30 天回收站，共享笔记继续保留；恢复只恢复本删除批次实际连带删除的内容。
5. 云同步、外部账号接入、AI 自动关联和图谱可视化后置。

| 页面 | 规格 | 状态覆盖 |
| --- | --- | --- |
| 对话入口 | 24dp 原 SVG；44dp 触控区，与现有侧边栏按钮一致；空会话常显，有消息时与新建会话并排 | 空白、有消息、返回保留上下文 |
| 统一笔记面板 | 保留原笔记本栏和列表；搜索标题及正文；置顶优先；黑底白“+”；标题栏回收站及展开入口；置顶/移动/删除/来源引用位于笔记操作菜单 | 紧凑、展开、上拉展开、下拉收起、有数据、首次空白、搜索无结果、静态占位、读取失败 |
| 笔记编辑 | 沿用现有类型路由和编辑器；新增正文引用选择器及来源面板入口 | 已保存、保存中、保存失败、引用目标删除 |
| 来源与引用 | 主要来源、补充书籍引用、正文笔记引用、反向链接四组 | 完整来源、来源删除、历史来源待确认、暂无引用 |
| 回收站 | 展示删除时间、剩余期限、连带内容；恢复或二次确认彻底删除 | 有内容、删除前确认、为空、恢复失败 |

本次明确复用原笔记面板，不再维护独立管理页及其 320dp 双栏布局。宽屏与手机沿用同一列表组件，编辑通过图四对应的统一编辑器打开；编辑器遵守顶部系统安全区。视口测量以 Flutter 可用 dp 为准，不将用户截图物理像素当 dp。

所有页面进入和数据读取均采用静态占位。普通信息通过既有 `AppToast` 呈现；会导致未保存数据风险的错误保留行内提示及明确的重试/继续编辑入口。
