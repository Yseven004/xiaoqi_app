## 实际设备与测量边界

用户重新连接的唯一设备为 Lenovo TB335FC。ADB 实测物理分辨率 1600×2560，density 320，系统 font_scale 1.0，逻辑画布 800×1280 dp。用户录屏被缩放为 720×1152，新增图片为 1080×1728，不能把这些像素直接当成 dp。

目标图是生成后确认的视觉稿，没有原始 Flutter/Figma 布局或 DPR。390 dp 用于比较组件的相对比例。真机验收按当时的设备、窗口和键盘设置比较。

用户随后明确：编辑／输入面板需要随设备适配，横向宽度与软键盘一致。此前“最大宽度 720 dp”和整棵控件树按平板宽度等比缩放的做法均撤销；面板铺满可用设备宽度，内部按钮、文字、图片缩略图仍按设计尺寸绘制。私密可见范围菜单仍是独立紧凑弹层，不随键盘宽度拉伸。

| 组件关系 | 还原约束 |
| --- | --- |
| 短输入 | 紧贴键盘上沿；单行引文位于下方；无默认主题输入下划线 |
| 有图输入 | 图片在文字/语音下方；缩略图与删除角标可辨；主界面最多三张 |
| 详情 | 单行引文 → 文字与音频 → 图片 → 紧跟的操作栏；不预留空槽 |
| 私密菜单 | 无尖角；入口上方留空；选中勾在右；未开放状态右列对齐；不遮入口 |
| 颜色 | 白/灰表面，黑色主要操作；虚线依据最终图与淡叶绿要求复核 |
| 编辑选区 | 聊天和伴读均能看到所注释范围；键盘不重新分页，编号不压正文 |
