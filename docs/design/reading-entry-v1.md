# 阅读任务：继续阅读与导入正文入口

创建：2026-11-12；更新：2026-11-13。状态：主界面入口位置、“继续阅读／导入正文”两个主要状态、第一张阅读页方向及精简导入面板已获用户认可。其余详细状态仍为提案，未进入正式实现。

## 已确认的产品方向

- 保留现有阅读空间主界面，承载任务切换、完整对话、技能/插件与 MCP。
- 第一版支持 PDF/EPUB 的书籍信息、目录和正文。2026-11-13 用户明确修订：选文菜单只保留“复制｜注释｜问 AI”，移除独立划线功能；“注释”承接此前“写想法”的用途，保存文字并关联原文。
- 用户选择扫描 PDF 范围方案 2：扫描页只做原页阅读，不新增 OCR；复制、选文注释和选文问 AI 用于 EPUB 与具有可用文字层的 PDF。混合 PDF 按实际页面文字能力处理，不能因为一页是扫描图就禁用整本书的选文能力。
- 选文问 AI 在阅读页的小对话窗口内进行，保留选文和阅读位置。阅读页采用用户选中的第一张方向。
- 用户于 2026-11-13 对主界面入口概念稿回复“这样确实也可以”，随后对精简导入面板回复“对，这样可以”。已确认这两处设计方向；当前仍在设计与范围确认阶段。

## 已确认的入口方向

在输入区上方、原有任务/技能/MCP 胶囊上方增加一条轻量状态栏。书名仍在任务胶囊中，状态栏不重复展示书名。保留既有聊天区域和输入区；有聊天时不替换聊天内容。

| 当前状态 | 信息栏 | 操作 |
| --- | --- | --- |
| 已有正文且有进度 | 已读 39% · 第四章（示例） | 继续阅读，恢复上次位置 |
| 已有正文、首次阅读 | 正文已就绪 | 开始阅读 |
| 已关联书籍但无正文 | 尚未导入正文；PDF / EPUB | 导入正文 |
| 未关联书籍 | 不显示本书状态栏 | 使用现有阅读任务入口 |
| 已关联文件但文件不可用 | 正文文件不可用 | 重新选择资料；不能显示虚假进度或视为首次导入 |

前两种首页状态与已选阅读页见 [概念流程稿](reading-entry-v1-concept.png)。这是生成式概念图，不是应用实际渲染截图；左、中是替代状态，不是顺序步骤。图中尺寸、文字和箭头只辅助审阅，具体行为以本文为准。

## 两条独立路径

1. 已有正文：主界面 → 继续阅读 → 已选阅读页；返回阅读空间时保留当前任务、聊天与输入草稿。
2. 尚无正文：主界面 → 导入正文 → 选择 PDF/EPUB → 精简文件确认面板 → 导入并阅读。书籍信息与目录自动读取；正常路径不要求逐项核对。

导入时不默认新建第二个阅读任务，不自动覆盖已有书籍信息。资料识别结果与现有信息有差异时，展示差异供确认。取消文件选择或确认流程返回原主界面；失败保留现有任务和数据，显示原因和重试入口。重复文件应复用现有资料。

## 阅读与对话衔接提案

- 小窗口问答关联当前阅读任务与选文引用；完整聊天和小窗口的具体展示、关闭/最小化/重新打开规则仍需后续细化。
- 从完整聊天的原文引用返回阅读页时定位对应原文，不能仅打开书籍首页。
- 图中的小窗口是选文提问后的状态；进入阅读页本身不自动选文、不自动打开 AI 窗口、不弹键盘。
- 已选阅读页概念图仍包含旧“划线”按钮；该处以 2026-11-13 的用户修订为准，最终菜单为“复制｜注释｜问 AI”。选中文本的临时蓝色选区仍用于选择范围，不保存为独立划线记录。不恢复听书、书摘等未确认动作。
- 书籍元数据、目录与可阅读正文分别显示实际识别结果；扫描 ISBN 不意味着已获得正文。

## 导入确认页初稿（2026-11-13，已被精简稿取代）

[导入确认概念稿](reading-import-confirmation-v1-concept.png) 延续已选界面方向，示意选择 EPUB 后、正式关联保存前的预览状态。示例中的文件大小、8 个章节与正文均为设计样例，不代表真实解析结果或已实现能力。

1. 从当前书籍的“导入正文”进入，默认关联当前阅读任务；底部确认面板展示文件名、格式和大小，可重新选择。
2. 书籍信息展示当前书籍与文件识别结果。缺少作者、封面不影响可读资料导入，不编造缺失值；已有信息保留。存在冲突时的比较与选择界面仍待细化。
3. 内容预览包含实际解析到的目录和正文片段，不能以“上传成功”冒充正文可读。PDF 以真实页预览呈现；未识别到目录时如实说明，不虚构章节。
4. “导入并开始阅读”成功后进入阅读页；关闭或取消返回原任务。解析失败不能启用成功路径，保留重新选择或重试入口；保存失败不新增空书籍或损坏已有资料。
5. 此初稿提出的扫描 PDF 范围问题已在后续确认：第一版仅原页阅读、不新增 OCR；目录缺失与元数据冲突等状态仍需细化。不得把本张 EPUB 成功态概念稿当作这些能力已验收。

该页仅为设计提案，不修改当前导入行为；概念图中的背景排版不覆盖已确认的主界面布局。

## 已确认的精简导入面板（2026-11-13）

用户反馈初稿“看上去过于复杂”。以 [精简概念稿](reading-import-confirmation-v2-concept.png) 取代前述完整信息核对界面，原图只保留为修订记录。

用户已确认此稿。默认成功路径的面板内容与简洁程度按此冻结；以下异常处理细节仍须落实，不能据此新增常规确认步骤。

- 面板仅保留“导入正文”标题与关闭、文件名/格式/大小与“更换”、“导入并阅读”主按钮；不展示元数据表格、目录列表和正文预览，不增加二次确认。
- 资料校验、元数据/目录/正文读取由应用完成；简化界面不代表跳过真实解析。已有书籍信息保留，缺失值不编造；仅信息冲突、文件不可读或保存失败等异常需要用户处理。
- 点击主按钮后显示明确的导入状态，完成后进入已选阅读页；失败停留并显示具体原因与重试/更换入口，不能进入空正文页。执行中取消与保存边界仍按数据完整性要求细化。
- 关闭或更换文件不改变原阅读任务；目录和正文在成功进入阅读页后查看。扫描页支持原页阅读，不展示不可执行的选文动作；不自动启动 OCR。
- 当前仅修改设计说明与概念图；未修改运行代码、未执行设备验证，无需服务端部署。

## 全局交互约束

- 页面进入/切换不使用转圈加载态；解析期间采用静态状态文字或骨架，并提供取消/失败恢复。
- 输入为空时收起键盘同时退出焦点；布局与键盘动画不得重新抢焦点。
- 点击按钮或空白退出当前输入焦点并保留文本，按钮首次点击即生效；点击另一个输入框正常转移焦点。
- 有内容时仅收起键盘不强制失焦；保留键盘和辅助技术主动聚焦能力。
- 最终固定图标优先复用既有独立 SVG；概念图不得作为界面或组件位图接入。确定新资产后按全局 SVG 清单与预览规则交付。
- 概念稿按用户原始 1080×1728 竖屏比例展示；实际逻辑尺寸、窄屏排列、键盘打开状态和大字体布局在下一阶段确定。

本地已见 `XiaoqiDocument` 保存章节、块、原文位置及修订相关信息；现有 EPUB 页面主要显示章节纯文本，解析存在不等于已满足图片、排版、选择与回跳需求。优先在现有模型上补足定位与呈现，不另建平行书库。
