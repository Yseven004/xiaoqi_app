## 确认流程

1. 新建插件进入编辑页，等待页面进场结束后打开创建／导入窗口；恢复草稿和编辑已有插件不自动打开窗口。
2. 创建窗口的 MCP 入口在同一弹窗路由内切换到现有 MCP 表单。遮罩保持连续，220ms 淡入淡出与 0.985→1 轻缩放；遵循系统减少动画设置。退出中的窗口不响应点击或辅助技术焦点。
3. MCP 提交沿用已有连接保存接口；成功后把名称和图标回填到当前插件草稿。服务器地址、访问令牌仍仅使用连接配置，不写入插件草稿、清单或展示资料。
4. 连接与插件草稿继续独立保存：MCP 添加成功即保存连接，编辑页的保存草稿继续保存插件资料。该改动不新增插件到 MCP 的执行绑定。
5. 表单关闭／取消不清空当前编辑页；连接保存失败留在 MCP 表单重试；测试连接不保存。编辑页底部操作栏在导入期间保持原位。首次导入空插件不显示替换空内容确认，已有编辑仍确认替换。
