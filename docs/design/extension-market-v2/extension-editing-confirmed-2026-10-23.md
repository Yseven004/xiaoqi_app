## 2. 技能与插件的共同编辑页

1. 顶部返回、居中「编辑资料」、归属与类型及草稿状态；右上角「导入内容」保持原位置，黑底白字配原有图标。用户明确仅增强按钮醒目程度，不改变布局，不另建导入区块。
2. 图标及「更换图标」与名称、一句话简介并排；下方为详细介绍及固定介绍图片区。图片可选，支持添加、排序、删除和简短说明。图标选择器共用内置矢量库、上传及恢复默认能力。
3. 「技能内容」与「插件内容」在相同位置默认折叠。前者显示实际主文件与附件；后者显示实际包内组件与文件摘要。展开后的具体操作不通过本张主页面截图推定，不自动新增可视化组件构建器。
4. 「导入内容」复用当前文件／链接导入弹窗及检查与取消能力；成功后回填同一草稿、关闭弹窗并停留在原编辑页。涉及覆盖已有修改时确认，取消或失败保留原内容；已有来源、格式与执行边界继续有效。
5. 底部「保存草稿」「预览」。预览只读展示最终详情效果，返回编辑保留同一草稿；用户点击「确认发布」才公开。仅作者可编辑和发布自己的作品，导入或安装本身不构成作者归属。

插件预览沿用已确认的技能预览外框与操作，内容按实际插件资料和组件展示；本轮未单独生成插件预览图，不把它记为已完成同状态视觉验收。原有插件功能与管理入口不因统一主表单而删除。

## 3. MCP 图标与连接表单

- 顶部为「连接设置」及现有说明，图标与名称并排；图标下方提供「更换图标」，复用技能／插件的图标选择器。首次创建使用对应的添加标题和「添加」按钮。
- 保留服务器地址、可选访问令牌及现有输入行为。保存已有连接时令牌留空保留已有值；不在设计示例或公开资料中写入实际令牌。
- 「测试连接」不保存配置；「保存／添加」同时保存连接资料和图标。列表、详情与聊天选择器使用同一图标。取消保留此前已保存的配置。
- 自己创建的自定义 MCP 连接可修改图标，作用于自己账号中的连接展示；从市场安装的 MCP 沿用发布者图标。
