# 已确认学习插件的运行接入

用户于 2026-10-26 确认笔记成品排版及传统批注符号。以下实现复用现有聊天、市场、原生笔记、私有任务和隔离脚本机制。

## 原文批注

- 官方原创 plugin.json + skill 组件 + 固定 Python 脚本；不开放任意绘图代码。
- 沙箱补入 Tesseract 中文/英文、Pillow 与 Long Cang（OFL），不增加 MCP 或 Android SDK。
- OCR 使用 hOCR 的真实字符框；先扫描，再由模型提交行 ID、唯一原文引用、固定符号枚举和简评。渲染前重新识别核对，拒绝模型自填坐标。
- EXIF 正向显示后原图不缩放、不重画。字符低置信度、重复引用、跨字片段、行间冲突、边批重叠或尺寸超限均明确失败；可删除局部不可靠标记后仅纠正一次。
- 原图保留在现有私有附件；生成 PNG 与私有收据。固定符号规则遵循已确认文档。关闭当前插件的生成图片工具，避免重画原文；Study Notes Studio 仍须真正调用图片模型。
- 回滚：当前不可变安装包仍固定旧版本；部署按标准单版本发布流程回滚。新字体附原始许可证。

## 学习笔记管家

- 普通聊天仍先满足用户问题。仅本轮明确启用的官方原生笔记插件可调用受控的笔记增量工具，不能因后台自动发现技能而开启。
- 复用当前任务请求/响应；不启动独立常驻服务器工作进程。工具仅产生私有笔记增量，不修改客户端笔记。
- 客户端发送已关联主题的 ID 与标题，模型只有确定同主题才选择已有 ID；否则新建。工具限制可选 ID 必须在本轮目录内，不能读写其他笔记。
- 增量为标题、简短概念、结构化小节/步骤，不接受任意富文本操作或替换命令。客户端转换为现有 Quill Delta，追加到最新本地快照，原有文本、富文本、嵌入和标题均保留。
- 本地 SQLite 事务保存待应用任务、主题映射与唯一回执；原生笔记和来源记录同事务写入，重复恢复不重复追加。现有笔记被删除时不复活，另建并明确反馈。
- 编辑器打开某笔记期间暂缓该笔记的自动追加，关闭后重新读取最新快照再追加，防止旧编辑器快照覆盖新补充。
- 应用非前台时暂停写入；恢复时重放现有私有任务的完成事件并处理本地队列。停用/卸载后停止新整理，保留既有笔记；取消不删已存内容。
- 状态复用现有聊天附近的轻量提示：整理中、已存且可打开、暂停、失败且可重试；不弹窗、不抢焦点、不引入路由转圈。
- 数据库增加队列/回执/主题映射表，不改写旧笔记。原生/服务端共享 release 与契约同时更新。

## 验收

1. 包内组件解析覆盖本地和市场来源；只信任服务端固定的官方包命名空间。
2. 批注检查字框、歧义、置信度、原图绑定、跨栏/相邻行避让、注释碰撞、像素保留，并运行真实 Tesseract/私有附件链路。
3. 笔记检查明确启用、跨聊天主题目录、只追加、编辑保护、持久队列、事务去重、暂停/恢复、停用/删除及来源回跳。
4. 本地检查和 CI 通过后标准部署；真机由用户验证。不能将单元测试冒充真实照片视觉验收或真机验收。
