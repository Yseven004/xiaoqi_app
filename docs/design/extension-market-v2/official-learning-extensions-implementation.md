1. 第三方官方精选：Study Notes Studio（学霸笔记图）、Book to Skill（书籍转技能）。固定原仓库提交，保留作者、许可证、正文及运行资源，适配小七工具与私有文件交付。

3. 官方原创：原文批注笔记。原图像素保留，OCR 定位后以受控图层添加红色批注及黄色重点；可拓展页边，导出 PNG。

## 发布、失败与回滚

首批使用当前市场安装链路和不可变包；启动时校验所有精选包后再同步目录，同版本重启不增加发布修订。旧安装固定旧包，不静默升级。保留原作者，界面说明“第七世界官方精选 · 第三方开源技能”。Book to Skill 产物默认私有 ZIP，使用现有上传导入，不暗示自动安装。

后端修改需本地检查、CI 精确提交构建与标准部署脚本；失败保持健康版本或自动回滚。接口契约及共享 release 标识按实际变更同步。

首批 release：`2026-10-26-official-learning-1`，接口契约 `23`（客户端与服务端同步）。精选来源字段由服务端生成；客户端需匹配版本后使用。

已完成本地服务端静态分析、201 项完整测试；提取测试覆盖中文章节和跨调用可读输出。部署前新增真实模型门禁，验证实际图片和技能 ZIP，不能以包安装成功代替任务成功。部署脚本本地测试通过，9 项依赖 Linux 的 Python 检查留给 CI。

批注样张 v1/v2 被用户指出定位偏离、手写感不足、符号错误，均未确认。v3 改为字框定位、重复引用拒绝猜测，并引入 Long Cang 字体；符号约定与研究在 `annotation-symbol-research.md`。当前仅为设计样张，不是已实现的插件。

真实验收发现并修复：资源读取工具需支持当前包的根目录 Markdown 和 handbook；验收容器需同时加入现有外网/沙箱控制网，并显式配置沙箱 URL；转换阶段需要现有 Python 文件生成工具。最后一项权限仅依据服务端不可变包的 `official-catalog/book-to-skill/` 命名空间，且必须是本轮适用技能，不能由自填作者、精选资料、名字或客户端声明获得。普通导入技能仍只运行包内脚本。生成的章节资料打入私有 ZIP，不误计为额外单独附件。

脚本执行按当前账号/本轮附件引用读取原始文件，避免只把附件元信息或空文本传成 PDF。归属检查复用附件服务，单份与合计输入上限 20 MB，超过需拆分；不把服务器凭据传进脚本。沙箱补入服务端已使用的 Poppler，供上游 PDF 提取回退使用。扫描 PDF 仍需检查既有 OCR 覆盖，不能据文本 PDF 的能力承诺全部扫描件正确。

两项技能真实模型验收已通过（图片、资源读取、提取脚本、Python 和技能 ZIP 均有实际证据）。首次激活被严格数据核验拦截，已自动回滚并验证旧服务。修正方式是：维护期先备份，在断网的独立命令中执行目录种子迁移，并导出精确文档/文件哈希增量；核验把这个受限增量合入基线，继续逐项比较全部数据，不忽略用户数据前缀。回滚仍用原始完整基线。SQLite 核验改为读取已提交 WAL 的只读事务，参照 https://www.sqlite.org/wal.html 。跨语言烟雾检查已验证 Dart 实际迁移与 Python 完整清单一致，且私有内容改动仍会失败。
