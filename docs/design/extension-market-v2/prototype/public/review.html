已确认的基础路径

插件首页保留顶部双页签、已安装图标、公开/个人和双列列表。添加菜单保留创建插件、上传压缩包、自定义 MCP。MCP 继续合并在插件中。

  1. 技能 → 添加 → 通过聊天创建：普通新会话带入创建引导；发送两轮消息可预览草稿交接。
  2. 技能 → 添加 → 使用编辑器创建：填写名称、描述与正文，添加文件或文件夹。
  3. 修改内容后返回：选择继续编辑、保留草稿或不保存。
  4. 技能 → 添加 → 从设备上传：Markdown 文件可预览编辑；压缩包仅演示交接，不真实解包。
