## 2. 三步创建与两种展开状态

| 阶段 | 已确认内容 |
| --- | --- |
| 添加内容 | 上传技能文件／压缩包，或填写「从GitHub上导入」。该标签前使用 GitHub 图标。保留「读取内容」操作；不显示读取后自动填写的底部提示，也不显示独立 AI／从零编写入口行。 |
| 补充资料 | 图标与名称同排，一句话简介可直接修改；名称和简介可由内容生成。详细介绍、介绍图片为可选项，资料页默认收起。AI 生成的文字可修改，不自动公开。 |
| 确认 | 使用用户最后选定的只读详情预览，显示尚未发布状态；底部「上一步」「保存草稿」「确认发布」。保存草稿与发布是不同动作，只有明确点击确认发布才公开；草稿支持删除，删除草稿不等同于卸载或删除公开作品。 |

**所有状态都保持同一弹窗外框、位置和尺寸。** 长内容在内部画布滚动；不得靠增高、移动弹窗或跳完整页面来容纳内容。进度条是连续轨道与连续填充，不能生成断续短线。

| 交互状态 | 呈现与行为 |
| --- | --- |
| 查看 | 点击详细介绍或介绍图片的查看／展开操作，只在原位置展开只读内容。其他资料、步骤及当前页操作仍保留；内部内容重排或滚动，不自动进入占满弹窗的编辑态。 |
| 编辑详细介绍 | 真正开始编辑文字时，正文画布占满同一弹窗；隐藏其他资料、创建步骤与上一页操作栏。顶部仅保留返回、当前标题及「完成」。 |
| 编辑／上传图片 | 编辑图片资料或添加图片时进入图片专注画布；同样隐藏其他资料与步骤，顶部保留返回、当前标题、布局菜单与「完成」。上传属于编辑动作，不把普通查看也变成专注编辑。 |
| 完成或返回 | 回到补充资料页，保留同一草稿及已编辑内容。普通查看不触发发布；确认页保持只读，需要修改时回上一步。 |

## 3. 图片布局与添加框规则

- 默认横向滚动；「完成」左侧的紧凑图标按钮打开布局菜单，只有「横向滚动」「网格布局」两项与选中标记。按钮没有下拉箭头；横向图标使用左右并排卡片，不能画成上下两行，菜单与按钮图标一致。
- 两种排版使用同一组图片、顺序和可选说明。排版属于该作品的展示设置，发布前预览与发布后的详情页都跟随所选排版；只读详情不显示删除、拖动、添加、布局编辑等控件。
- 添加入口是图片队列末尾的虚线框，随图片一起滚动，不另放独立「添加图片」按钮。有图片时，添加框与紧邻前一张图片的**显示宽度、高度及宽高比一致**；没有图片时默认**宽 3、高 4（3:4 竖向）**，不是正方形，也不是三行四列。末图改变后，添加框跟随新的末图；全部删除后回到 3:4。
- 专注画布内保留图片删除、拖动排序及可选说明。减少图片区域下方的大块留白，将空间留给预览与编辑；外框和顶部操作保持固定，图片按原比例展示，不拉伸变形。
- 当前截图是设计参考。生产图标与固定形状优先复用已有独立 SVG，接入前完成独立预览及资产清单；不能把确认图裁片或整张截图当作页面、按钮或图标资产。
