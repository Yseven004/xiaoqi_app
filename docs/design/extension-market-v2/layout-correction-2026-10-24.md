# 创建弹窗第二轮几何修正

依据：用户 2026-10-24 提供的两张当前设备截图、对应技能／插件原型和 `125b7bb0385f7c611f57e781ec094f28.mp4`。不改变已确认三步流程。

原型弹窗宽度约为画面宽度的 80%，技能高宽比约 1.27、插件约 1.32；内容侧边距约为弹窗宽度的 6%。当前设备截图的弹窗偏宽、靠上，侧边距小，上传区偏扁、图标偏小，输入区与底栏之间出现过大空白。

本轮以原型比例收窄并下移外框，统一标题、内容、分隔线和底栏的左右基线。上传区按宽度确定高度（技能 1.84:1，插件 1.98:1），窄屏保留最小内容高度并滚动；放大文件上传图标、主提示和选择文件操作。GitHub 字段统一圆角灰底，MCP 标题区增加分隔并区分主标题与括号说明。未改 API、草稿格式、读取校验和发布行为。

键盘问题：旧实现从内容区直接扣除整个键盘高度，忽略键盘仅与弹窗下部相交，导致滚动视口被过度压缩。本轮依据弹窗顶部和键盘顶部的交点确定内部可见高度，去掉内容区的键盘底部填充；外框尺寸与位置固定。键盘显示时暂时隐藏推进底栏，留出可滚动表单，收起后恢复。弹窗局部关闭按钮、上传区及折叠控件的按压蒙层、水波纹和按压阴影，保留焦点与禁用状态。

验收状态：代码修正与独立 SVG 预览已完成；格式及差异检查完成；静态分析无 error，仍有既有风格提示和上一轮移除首屏入口后遗留的 `_aiAssistance` 未引用警告。Impeccable 布局检测返回空结果，但其 Dart 覆盖不足，不作为视觉通过依据。未运行应用或执行设备操作，未执行真机验证，待用户真机验证。当前不能声称与原型像素一致。
