## 原文批注笔记

使用标准 plugin.json 与技能组件；脚本固定在不可变包中，部署沙箱提供 Tesseract 中文/英文、Pillow 与 Long Cang。字体来自已归档 Google Fonts Long Cang，SIL OFL 许可证与字体一并进入沙箱。原图按 EXIF 正向显示后不缩放、不重绘；只添加动态批注图层。没有新增 MCP 或 Android SDK。

扫描使用 hOCR 字框与置信度。模型只提交行 ID、唯一原文引用、固定符号和简评；渲染时重新识别比对，不能自填坐标。低置信度、歧义、字框不符、行间冲突和边批碰撞均拒绝绘制。已有页边只有经像素检查确认空白才复用，避免批注远离原文或压住插图。不够的页边向外拓展。箭头仅连接避让移位的边批，使用完整双翼箭头头部。

OCR JSON 与收据是私有中间产物，任务内继续复用；运行层依据官方包绑定标记 internal，客户端不将这些文件作为交付卡片展示。用户交付为真实 PNG。原图和原有附件保留，不把用户提供的教材照片打入公开包。

上限为单图 20 MB、800 万像素、画布 1200 万像素、无损 PNG 10 MB、每页最多 16 处批注；超限明确请求单页裁切，不悄悄压缩原图。倾斜或模糊图片失败时可换清晰单页重试。

## 学习笔记管家

仅明确选中的官方包可使用 append_learning_notes，不通过自动发现启用。正常讨论后产生结构化增量；有顺序的步骤使用原生编号列表，并列内容使用项目符号。新主题先写核心概念，后续只追加。主题目录只提供关联主题 ID 与标题，确定同主题才合并，不接受其他笔记 ID。

增量在现有私有任务中传输，通过原生 SQLite 队列、主题映射和回执事务写入现有 Quill 笔记与聊天来源。重复恢复不重复追加，跨账号检查请求开始时的身份。主聊天不中断；本地存储失败仅显示整理状态，不冒充已经保存。

编辑中的笔记暂缓追加；旧编辑快照保存时，还会合入快照之后已经完成的自动补充，防止打开瞬间的并发覆盖，并同步到编辑器。用户原有文字、格式、图片嵌入和手动标题保留。应用非前台暂停本地写入，重开只查询已有私有任务并处理持久队列，不启动独立常驻服务器作业。停用/卸载或聊天清除选择后不处理待写队列，原笔记保留；删除的笔记不会被自动复活。

数据库 34→35 只增加队列和主题映射表。服务端/客户端更新相同 release 与契约。取消、未完成或中断的服务端任务不向原生层交付新增笔记。
已合并主分支的暂停/恢复修复，共享 release 为 `2026-11-03-learning-plugins`，接口契约 `27`，不回退暂停/恢复逻辑。
