# 阅读批注符号研究与本插件约定

2026-10-26。用户纠正：使用人类常见的阅读批注符号，不能让 AI 为装饰效果随意编造。此前样张的符号定位、含义和手写感不合格，尚未确认。

## 一手与教学来源

- 徐汇教师网，徐汇区东安三村小学顾凤娇，2023-06-08：[用“批注的方式阅读”的单元教学实施探索](https://tpd.xhedu.sh.cn/cms/app/info/doc/index.php/92785)。明确列出：问号放在疑问词句旁、直线放在有感悟的句子下、三角形放在关键词下。说明三角形不是天然错误，错误在于无语义、位置错误或混乱使用。
- 国家中小学智慧教育平台，统编七年级下册语文，名著导读“圈点批注”第 80 页：[教材 PDF](https://v1.ykt.cbern.com.cn/65/document/206240c75072408bb343d0c403696efa/pdf.pdf)。检索可见段落列举圆点/圆圈、问号、叹号、直线、波浪线及层次分隔线，并强调设定后固定使用。此链接正文抓取返回 403，不能宣称已完整审阅该 PDF。
- 武汉教育云教学资料：[小学语文批注式阅读教学研究](https://whty-msmx-public-source-1256736654-cdn.huijiaoyun.com/420100/uploads/studio/ue/2023/11/12/6550c4be6c241/1699792062_4429_81240.pdf)。检索可见符号表，包括圈、方框、自然段编号、分隔号、波浪线、三角形、双横线、问号与转移箭头。使用前核对正文，不把检索片段说成完整阅读。

## 拟用固定图例（产品约定，非国家统一标准）

| 符号 | 用途 | 放置要求 |
| --- | --- | --- |
| 圈、点、字下小三角 | 关键词、生字难词或需要强调的词语 | 圈包住对应字词；点和小三角按字下排，不盖住文字 |
| 直线、双横线 | 重要语句；双横线用于中心/总起等核心句 | 贴对应文字下方；跨行逐行画，不划空白或跨栏 |
| 波浪线 | 值得赏析的语言、描写和修辞 | 贴相关句子下方；不会同时表示“文字错误” |
| ？、！ | 具体疑问、感悟或强调 | 放在对应词句旁，并配必要文字解释；没有疑问不装问号 |
| 段号、分隔线、括线、箭头 | 段落层次、范围与批注对应关系 | 括线限定具体段落；箭头只连接边批与准确原文锚点，不作装饰 |

黄色荧光重点是视觉辅助手段，不另发明“黄色＝某种修辞”的编码。不强迫每页出现全部符号。

## 定位与质量门槛

符号必须来自可验证的原文引用和坐标。跨行按行拆分；重复短词必须带上下文消歧；无法唯一定位时跳过/提示，不估算位置。手写风格仅作用于批注字和笔迹，不能以抖动掩盖错位。注释写在邻近空白，避让原文、图像与已有标记；空间不足再拓展外边距。

字体候选 Long Cang：[原作者项目](https://github.com/googlefonts/longcang)，Google Fonts 分发，SIL OFL 1.1。样张字体与许可证在 `fonts/`；尚未进入 App。手写字体本身不代表已达到用户参考图的真实手写效果。
