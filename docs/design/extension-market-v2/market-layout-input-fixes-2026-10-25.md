## 本轮确认的范围

1. 技能/插件公开推荐只有一个条目时，从正常列表左侧开始。共享 `MarketGrid` 明确占满可用宽度，保留现有双列断点与列宽。
2. 创建流程的添加内容、补充资料、确认统一外框宽高、起点与进度条。采用已有添加/确认步骤的规则；补充资料仍可在内部滚动查看全部内容。此项覆盖旧定稿中单独加高补充资料与使用圆点进度条的记录。
3. 详细介绍保持外框与底部说明位置；键盘遮挡时只缩小实际可编辑视口，长文本在画布内部滚动。右上角复用主界面扩展 SVG，点击展开/收起输入画布，保持同一个文本、焦点和滚动控制器；完成返回资料，展开状态下的返回先收起。保留空内容收键盘失焦、按钮单次点击执行、禁止布局重新抢焦点的全局规则。
4. “有未保存修改”提示仅保留继续编辑、保存后退出两个按钮；提示右上角 × 返回 discard 并退出整个创建流程。点击遮罩或系统返回仍返回继续编辑，不隐式丢弃。已有保存流程及其他页面的关闭默认行为不变。
5. Android 文件选择显示所有类型，选择后继续使用现有服务端策略进行文件名/格式、大小和内容检查；其他平台保留扩展名筛选。不会新增存储权限或改变导入/API 数据格式。
6. 介绍图片网格从左上角开始，首张与后续图片使用同样列宽，保持比例且不过度缩小；单张不再收缩网格宽度，增删图片时不改变列规则。横排、拖动排序、最多六张和旧 caption 保留规则继续有效。

## 来源与实现依据

- 本轮用户提供的五张 JPG 与两段视频为问题证据；后续口头纠正明确要求“左上角”，不是右上角或新增图片缩放控件。
- 主界面输入扩展交互参考 `lib/pages/home_page.dart` 的现有展开/收起行为。本轮复用 `assets/images/home_composer_expand.svg`，viewBox `0 0 256 256`，显示 20×20，48×48 点击目标；消费者为详细介绍画布右上角按钮，状态语义为展开/收起，无新视觉资产或依赖。
- 已阅读现有 `file_picker 13.1.0` / `android_file_picker 2.0.1` API 与源码，参考仓库为 [flutter_file_picker](https://github.com/vicajilau/flutter_file_picker)，MIT；只使用已安装依赖的公开接口，未复制或修改依赖实现。
- [Android Storage Access Framework 官方说明](https://developer.android.com/training/data-storage/shared/documents-files)（查阅日期 2026-10-25）说明系统选择器使用 MIME 类型过滤。不同文件提供方类型标注可能造成隐藏是本轮源码推断，未经目标设备验证；最近文件索引及起始目录由系统文件提供方决定，本轮不承诺控制它们。
