## 创建与试用

从现有创建入口插入能力标签，在当前聊天描述用途。信息不足时自然追问；目标清楚后生成完整草稿。纯文本技能直接展示代表性试用；脚本技能按授权策略进入 Docker 加额外沙箱试用。结果出现后沿用“直接保存 / 修改后再看”，保留“在胶囊中显示”开关。运行失败显示原因及重试入口，草稿保留但不标为试用成功；取消停止任务并保留草稿，不创建正式版本。

## 公开 GitHub 导入

在“管理我的能力”中增加“从 GitHub 导入”。粘贴仓库或技能目录链接，点“检查链接”；检查中显示静态文字。单技能直接显示预览，多技能显示可选择列表。预览展示用途、来源、兼容状态，以及是否需要运行程序/联网；版本、许可证和依赖详情放在可展开信息中。

点击“导入”只保存技能包，不自动执行代码；成功后提供“试用”。技能可以先保存为“未试用”，不将导入成功标成运行验证通过。链接错误在输入旁提示；无技能、下载失败或不兼容显示原因并保留链接；返回取消不保存半成品。需要凭证或专用工具时明确提示缺项。

## 使用与运行授权（本轮主要待定项）

复用手动能力标签和已有技能摘要发现。纯文本无需额外运行确认；脚本执行的授权频次需用户决定。

推荐：同一技能版本与资料/联网范围首次运行时确认，后续在已授权范围内复用；脚本变更或权限扩大重新确认。必须明确许可是否跨任务保存，以及管理面板的撤销入口。替代方案：每次任务执行脚本前确认，许可只用于当前任务。

授权界面采用用户能理解的描述，例如“此技能将运行程序处理你选择的表格”，列出资料范围和联网用途，操作为“允许运行 / 取消”；不要求选择 Python 或 Node。具体布局待授权策略选定后展示视觉稿，尚不实施。

执行期间显示文字状态及“停止”。停止处理中不误报已停止；重连查询原任务，避免重复执行。完成后在聊天展示结果和实际产物；文件保存失败保留领取入口。离线可查看本地技能，执行时提示需要联网。

## 共用状态与边界

加载使用静态占位或文字，页面跳转不使用转圈。失败不清空输入，禁用按钮说明原因，长内容可滚动，键盘不遮挡操作，关键按钮具备可访问标签。沿用现有视觉资产；新固定图形冻结后按项目 SVG 交付规则接入。

本轮只确认交互，不改变本地优先策略，不增加私有 GitHub 授权或用户插件创建。多用户容器隔离后置，Docker 加额外沙箱保留。
